# 欧洲通用避坑规则

英国订单的硬约束主要是“景点闭馆日”。欧洲多出四类英国不会遇到的坑：**跨国交通、票务激活、退税、周日关门**。这些坑不在任何一份城市模板里，因为它们发生在模板与模板的接缝处。

制作任何欧洲订单前必须通读本页；每天质检时，除了《质检清单》的12项，再加上本页末尾的欧洲专项检查。

## 一、火车票务：激活与站台

- **意大利：纸质票必须在站台绿色机器打卡，电子票必须在App内点Check-in。** 不打卡罚款极重，且不接受“不知道”的解释。
- **威尼斯机场至Mestre、罗马Leonardo Express：上车前在黄色/绿色打票机激活。** 车票不限班次，激活才计时。
- **威尼斯水上巴士：上船前在码头打卡机打票。**
- **巴塞罗那交通票不可共用**，每人必须持一张，查票罚€100。
- **站台号提前10–15分钟才公布**，必须写“进站后看大屏幕确认站台”，不要在客户文件里写死站台号。
- **意大利火车出发前5分钟停止检票。**
- **车票不要拖到出发前几分钟买，票价会暴涨**（Trenitalia、SNCF均为动态定价）。跨国高铁建议提前3–7天，旺季更早。
- 购票渠道：意大利Trenitalia／Trainline；法国SNCF Connect／Trainline；瑞士SBB Mobile；德国DB Navigator（用Bayern Ticket要勾选local transport）；奥地利ÖBB。

## 二、跨国换乘：同名不同站

这是欧洲订单最高频的事故点。客户文件里**必须写全站名**：

| 城市 | 容易搞混的站 | 规则 |
|---|---|---|
| 威尼斯 | Santa Lucia（主岛） vs Mestre（陆地） | 高铁到S.Lucia；去米兰的车和夜车从Mestre发 |
| 巴黎 | 里昂站（意/瑞方向）、北站（比利时/伦敦）、CDG、ORY | 跨国方向决定用哪个站 |
| 罗马 | Termini（中央）、FCO（机场） | Leonardo Express连接两者 |
| 慕尼黑 | 中央站 vs 各支线站 | 富森、贝希特斯加登方向从中央站发 |
| 格林德瓦 | Grindelwald主站 vs Grindelwald Terminal | 住镇上在主站下；上少女峰从Terminal走 |
| 因特拉肯 | Interlaken Ost（东站） vs West | 山区方向全部走东站 |

## 三、退税：申根 ≠ 欧盟，瑞士是另一套

- **退税要在离开欧盟的最后一站办**，不是在购买国办。
- **瑞士不属于欧盟。** 从瑞士进入意大利/法国时，必须在边境（如 Domodossola 站）找海关给瑞士的退税单盖戳，否则后面在罗马或巴黎机场无法处理。这条已在《罗马通用》离境表里踩过。
- 机场流程顺序：**先退税，再托运**。无论物品在托运行李还是随身。
- 罗马FCO已数字化退税，自助机扫护照即可；退税区在200–300号值机柜台附近。
- 人工柜台盖完离境章，退税流程才算完成。
- 巴黎：老佛爷0层办退税（信用卡约11.4%），人多；巴黎春天人少更快。瑞士起征点通常CHF 300。

## 六、着装与场所规定

宗教场所**不能露肩，裙子或短裤必须过膝**，否则拒绝入场。涉及：

- 梵蒂冈圣彼得大教堂（最严）、罗马万神殿、圣依纳爵堂
- 巴塞罗那圣家堂（另禁吊带、无袖、露脐）
- 米兰大教堂（不能露肩膀，建议带薄披肩）
- 巴塞罗那主教堂

其他现场规定：

- 罗马西班牙阶梯**禁止坐下或吃东西**，有警察巡逻吹哨。
- 威尼斯圣马可广场**严禁喂鸽子**，罚款极高。
- 新天鹅堡室内**全程禁止拍照**。
- 皮蒂宫内部禁止闪光灯。

## 七、常见骗术与安全（写进客户备注）

- **强行套红绳／手绳**：罗马西班牙阶梯、巴黎蒙马特圣心堂门口。递过来就走开，接了就被索钱。
- **假角斗士合影**：罗马斗兽场外围，合影后索要€20–50。
- **街头赌局／围观魔术**：米兰森皮奥内公园一带，是骗子在找目标。
- **扒手重灾区**：罗马许愿池、威尼斯圣马可广场、巴黎地铁与蒙马特、布拉格查理大桥、布达佩斯游客区。统一写法：包背在胸前。
- **游客陷阱餐厅**：门口有人极度热情拉客、菜单只有英文没有当地语言、门口不标价——一律避开。意大利结账要核对是否已含Coperto服务费。
- **假纪念品**：柏林东边画廊沿街的“柏林墙碎片”；穆拉诺岛外的玻璃制品（认准 Vetro Artistico Murano 标识）。
- **海滩推销**：巴塞罗那沙滩上的按摩、编辫子、莫吉托一律不理。

## 八、山区与天气（瑞士、意大利南部）

- 瑞士所有山顶项目都必须写**天气不佳的替代方案**，否则等于没做。
- 少女峰3454米、瑞吉山1797米，即使夏天也需防风外套；10月山顶约5–10℃。
- 卡普里蓝洞**受天气和潮汐影响极大**，出发前查Blue Grotto Status，Closed立刻改去Anacapri。
- 阿马尔菲海岸SITA巴士：去程坐右侧、返程坐左侧；晕车提前吃药；末班车必须确认。
- 缆车、齿轨、游船末班时间全部要按客户日期在官方App重查。
