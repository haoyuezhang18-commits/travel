# 知识库更新规则

## 什么时候更新

每完成一个订单或发现模板错误后，进行一次简短复盘。

## 需要沉淀的内容

- 新出现且未来可能复用的城市模板。
- 现有城市模板的新交通版本或住宿版本。
- 新景点的实用说明。
- 已验证更顺的城市内部路线。
- 高频闭馆、年龄限制、停车或交通陷阱。
- AI 重复出现的错误及防错规则。

## 不要过度沉淀

以下内容通常不单独建立模板：

- 只出现一次的普通跨城自驾路线。
- 每个客户独有的完整 10 天／15 天组合。
- 简单导航即可完成、没有特殊坑点的交通段。
- 未经人工确认的 AI 临时建议。

跨城路线只有在重复出现、存在明显坑点或有固定换乘／停车策略时才升级为长期资产。

## 更新步骤

1. 更新城市资料卡中的“现有版本、默认路线、适用场景”。
2. 记录模板已知问题和核对日期。
3. 更新总索引。
4. 原始 DOCX 只有在人工确认后才修改。
5. 提交 Git 版本时写清楚修改原因，例如：`更新约克模板：修正城墙关闭时间`。
