# 模板陷阱：踩过的坑

每条都是真出过错的。做逐日行程前扫一遍，出稿后按《[质检清单](质检清单.md)》再核一遍。

## 一、多天套装：不要把"一天版"拆成两天用

**8 个模板文件内部分了"几天"的节**，同一节里的几张表是配套设计的，景点在天与天之间已经分配好，拆开或混用就会出现"第一天塞爆、第二天没内容"。

| 模板文件 | 内部分节 | 对应编号 |
|---|---|---|
| 佛罗伦萨通用.docx | 佛罗伦萨一天 / **佛罗伦萨2天** | 一天版 `FLR-R02`、`FLR-R03`；**两天版 `FLR-R01`（Day1 乌菲兹）+ `FLR-R04`（Day2 皮蒂宫）** |
| 罗马通用.docx | 罗马一天 / 罗马两天 | 一天版 `ROM-R03-A/B`；两天版 `ROM-R04-A` + `ROM-R04-B` |
| 爱丁堡两天通用版本.docx | 爱丁堡两天 / 爱丁堡1天 | 两天版 `EDI-R01` + `EDI-R02`；一天版 `EDI-R03` |
| 巴黎行程通用计划.docx | 巴黎两天通用 / 巴黎3天通用 | 两天版 `PAR-R03-A` + `PAR-R02`；三天版 `PAR-R05-A` 起 |
| 伦敦通用模板_已加索引版.docx | 伦敦2天通用 / 特种兵一天 / Day1–Day3 | 三天套装 `LON-R05` + `LON-R03-C` + `LON-R01-B` |
| 柏林两天.docx | 柏林 Day1 / Day2 | `BER-R02` + `BER-R03`（抵达日另有 `BER-R01`） |
| 慕尼黑三天.docx | 三天计划 / Day2 天鹅堡 / Day3 国王湖 | `MUC-R01` + `MUC-R02` + `MUC-R04` |
| 巴塞罗那＋Tossa 3天.docx | Day1 / Day2 / Day3 | `BCN-R01` + `BCN-R02` + `BCN-R03` |

**做法**：客户在某城停留几天，就去找对应的"几天"分节整套用。分节标题在 DOCX 里是普通段落，Ctrl+F 搜"两天""3天"就能看到。

> **真实事故**：佛罗伦萨排两天，我拿"一天版"拆成两天，结果第一天塞满、第二天只剩乌菲兹加逛街，客户一眼看出太空。正确做法是用两天版：Day1 乌菲兹、Day2 皮蒂宫＋波波里花园。

## 二、选版本：先按内容筛，再挑图最多的

图片数基本等于模板的新旧和精细程度——**图多的通常是最近做过、机位和备注都补齐的版本，图少的多是早期草稿**。

`python3 tools/取路线.py --list 罗马` 会直接列出图片数：

```
ROM-R03-A    图 10  西班牙阶梯＋许愿池＋万神殿线      ← 选这个
ROM-R02      图  5  斗兽场＋古罗马广场＋南线
ROM-R01      图  2  抵达罗马｜FCO落地至Termini      ← 早期版本
```

> **真实事故**：罗马两天全挑了图最少的版本（2 图和 5 图），而同城有 10 图的版本。换版后整份文档图片从 42 张涨到 68 张。

**但内容正确性优先**：客户说"入内只去乌菲兹"时，就得选不含学院美术馆的版本，哪怕它图更少。

## 三、转场版模板用在非转场日，要删掉后半段

很多模板是"某城最后一天＋转场去下一城"的合体，后半段是取行李、候车、火车、抵达下一城、下一城晚餐。**客户当天不转场时，这些行必须整段删掉**，再补当天下午和晚上的内容。

> **真实事故**：`FLR-R04` 是"皮蒂宫上午＋下午转场威尼斯"版。这单第二天仍住佛罗伦萨，后半 7 行（取行李→SMN候车→火车→抵达威尼斯→圣马可夜景）全部要删。

同类还有：`VCE-R03`（主岛＋转场）、`LUC-R04`（瑞吉山＋转因特拉肯）、`PSA-R01`（比萨→罗马）、`BIC-R01`（比斯特→银石）。

## 四、纵向合并单元格：写两次只显示后写的

模板里常有两行共用一个「时间段」格（纵向合并），比如"剪影机位"和"米开朗基罗广场看日落"。**对这两行分别改时间，只有一次会生效**。

**做法**：合并格一次写全，例如直接写 `19:00 - 20:15` 覆盖两行，不要分别写 `19:00-19:15` 和 `19:15-20:15`。

## 五、关键词要唯一，且默认只匹配「行程内容」列

- **备注列会顺带提到别的景点**：古罗马广场那行的备注写着"从后门6出口出去就是真理之口"，按整行匹配就会改错行。
- **一个词会命中多行**："万神殿"同时命中「万神殿（内部参观）」和「午餐（万神殿附近）」；"梵蒂冈博物馆"同时命中「前往梵蒂冈博物馆报到」和「梵蒂冈博物馆＆西斯廷」。

**做法**：用能唯一定位的词（`（内部参观）`、`西斯廷`、`台伯河畔漫步`），必要时用 `精确: true` 做整格全等匹配，或 `配列: "交通"` 指定按哪一列匹配。

## 六、交通段要保姆级

转场日不能只写"落地"，要**从酒店退房一路写到登机／上车**：退房检查 → 怎么去机场（几种方式、价格、耗时）→ 值机托运 → 安检 → 候机 → 登机 → 飞行 → 取行李 → 进城 → 入住。

同一段路给出 2–3 种方式并标出各自的价格和耗时，让客户自己选。

## 七、字符串替换改不了行，也常常改不动

- **Word 会把一句话拆进多个 run**，按文字节点做替换经常匹配不上（实测整天 0 处生效）。
- 字符串替换**改不了行的增删和顺序**。

**做法**：一律用行级操作（`删` / `改` / `增` / `序`），见 `tools/拼行程.py`。

## 八、表格必须插在对应标题之后

用 `body.append()` 追加表格会把它放到 `sectPr` 之后，**所有表格堆到文档末尾、彼此黏连**，前面是一大坨标题文字。必须插在各自标题后面，并在表后留一个带段后间距的空段。

## 九、别重打内容——图片会全丢

模板里的图片、字体、列宽、`●` 分点都是一单单攒出来的。把内容重新打一遍等于全扔掉。

> **真实事故**：第一版逐日行程是重打的，生成出来 **0 张图**，而对应模板里有 42 张。

**做法**：用 `tools/拼行程.py` 把 `w:tbl` 整个搬过去，只改变量。
