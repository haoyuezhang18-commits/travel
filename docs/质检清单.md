# 交付质检清单

规则本身在 [`铁律.md`](铁律.md)。这一页只讲**怎么查**——AI 最容易犯的 8 类错误，以及每天做完后的快速勾选。

## AI 最容易犯的 8 类错误

### 1. 时间错误

- [ ] 固定时间是否与客户截图一致？（真实事故：客户给的火车是 15:34，AI 写成 18:15）
- [ ] 出发时间是否默认得太早？（AI 惯性写 08:00，客户要求 09:00–10:00）
- [ ] 午餐、晚餐是否直接漏掉？
- [ ] 是否把寄存行李误写成上午入住？
- [ ] 是否把闭馆时间误当成最后入场？

### 2. 人数错误

- [ ] 是否残留原模板人数？（真实事故：客户 2 大 2 小，AI 照抄 2 人模板）
- [ ] 儿童年龄是否写了？
- [ ] 有年龄限制的项目，是否给了不能参加时的替代方案？（写了"8 岁以下不能登塔"却没给替代）

### 3. 擅自精简（**持续发生，最高频**）

- [ ] `●` 分点是否还在？有没有被压成一整段文字？
- [ ] 景点详细说明是否被无故删掉？（真实事故：博罗市场的美食清单被删）
- [ ] 停车、咖啡厅、洗手间、拍照机位说明是否被删？（真实事故：爱莲朵娜城堡的停车和洗手间说明被删）

### 4. 顺序错误

- [ ] 客户给了明确顺序的，是否照做？
- [ ] 景点顺序有没有排反？（真实事故：坎特伯雷→白崖 被写反）
- [ ] 模板顺序与开放时间有没有冲突？
- [ ] 一天内是否出现明显折返？

### 5. 格式错误

- [ ] 是否仍是四列表格？
- [ ] `●` 分点符有没有变成乱码？
- [ ] 时间格式是否统一？

### 6. 新增内容遗漏

- [ ] 客户点名要去的景点，是否真的写进去了？
- [ ] 客户给的具体信息（价格、班次、餐厅名、拍照机位、酒店）有没有漏？

### 7. 确认过的变量未生效

- [ ] 客户说"顺序改成 A→B→C"，写出来是不是 A→C→B？
- [ ] 客户说"加一个 XX"，有没有忘？
- [ ] 人数、交通、出发时间、住宿是否在**所有相关行**都一致？还是只改了标题、正文仍是旧的？

### 8. 擅自添加

- [ ] 客户说"下午自由活动"，AI 有没有自己塞进国家美术馆？
- [ ] 客户标的"可选"，有没有被写成必去？
- [ ] 有没有重复安排前几天已经去过的景点？

## 每天完成后的快速勾选

- [ ] 日期和星期正确
- [ ] 人数及儿童年龄正确
- [ ] 固定时间与客户截图一致
- [ ] 开放时间允许入内（当天不闭馆）
- [ ] 午餐和晚餐都在
- [ ] 路线无明显折返
- [ ] 酒店入住／寄存表述正确
- [ ] 无旧客户信息残留
- [ ] 无重复景点
- [ ] 可选与必去区分明确
- [ ] 客户新增要求全部落实
- [ ] `●` 分点和详细备注保留
- [ ] 文件里没有内部备注（"沿用模板""参考了XX"之类）

> 模板本身的坑（多天套装、转场版残留、合并单元格、选版本）单列在《[模板陷阱](模板陷阱.md)》，做之前先扫一遍。

## 用 拼行程.py 出稿时，这几条自检必查

工具会自动查前三条，人工确认后四条：

- [ ] **时间倒流**：有没有某一行的开始时间早于上一行
- [ ] **时段完全重复**：两行时间段一模一样（交通备选除外）
- [ ] **旧客户信息残留**：行程内容里还留着别的城市名、上一单的日期
- [ ] **版本选对了吗**：同一城市多个版本时，先按内容筛，再挑图片最多的那版
- [ ] **关键词有没有撞车**：改行用的关键词是否唯一？"万神殿"会同时命中"午餐（万神殿附近）"
- [ ] **交通段是不是保姆级**：转场日要从酒店退房一路写到登机／上车，不能只写"落地"
- [ ] **表格之间有没有空段**：表格直接相邻会在 Word 里黏成一张
- [ ] **多天城市有没有用配套的"几天"版**：不要拿一天版拆成两天，会导致第二天太空
- [ ] **转场版模板的后半段删干净了吗**：客户当天不转场时，取行李／候车／火车／下一城的行全要删
- [ ] **纵向合并的时间格是不是只写了一次**：两行共用一格时要一次写全
- [ ] **图片还在吗**：搬表后图片数应与模板一致，为 0 说明内容被重打了

## 欧洲订单再加

- [ ] 跨城车次的出发站名写全了？（威尼斯 Santa Lucia 还是 Mestre／哪个巴黎站）
- [ ] 需要打卡激活的车票，备注里写了？
- [ ] 落在周日／周一的市场和博物馆，营业状态查过了？
- [ ] 预约项目的提前期够不够？（斗兽场 30 天、《最后的晚餐》2 个月）
- [ ] 宗教场所着装提醒写了？
- [ ] 山区／海岛项目有天气替代方案？
- [ ] 涉及瑞士的行程，退税盖戳提醒写了？
