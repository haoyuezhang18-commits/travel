# 交付质检清单

规则本身在 [`铁律.md`](铁律.md)。这一页只讲**怎么查**——AI 最容易犯的 8 类错误，以及每天做完后的快速勾选。

## AI 最容易犯的 8 类错误

### 1. 时间错误

- [ ] 固定时间是否与客户截图一致？（真实事故：客户给的火车是 15:34，AI 写成 18:15）
- [ ] 出发时间是否默认得太早？（AI 惯性写 08:00，客户要求 09:00–10:00）
- [ ] 午餐、晚餐是否直接漏掉？
- [ ] 是否把寄存行李误写成上午入住？
- [ ] 是否把闭馆时间误当成最后入场？

### 2. 人数错误

- [ ] 是否残留原模板人数？（真实事故：客户 2 大 2 小，AI 照抄 2 人模板）
- [ ] 儿童年龄是否写了？
- [ ] 有年龄限制的项目，是否给了不能参加时的替代方案？（写了"8 岁以下不能登塔"却没给替代）

### 3. 擅自精简（**持续发生，最高频**）

- [ ] `●` 分点是否还在？有没有被压成一整段文字？
- [ ] 景点详细说明是否被无故删掉？（真实事故：博罗市场的美食清单被删）
- [ ] 停车、咖啡厅、洗手间、拍照机位说明是否被删？（真实事故：爱莲朵娜城堡的停车和洗手间说明被删）

### 4. 顺序错误

- [ ] 客户给了明确顺序的，是否照做？
- [ ] 景点顺序有没有排反？（真实事故：坎特伯雷→白崖 被写反）
- [ ] 模板顺序与开放时间有没有冲突？
- [ ] 一天内是否出现明显折返？

### 5. 格式错误

- [ ] 是否仍是四列表格？
- [ ] `●` 分点符有没有变成乱码？
- [ ] 时间格式是否统一？

### 6. 新增内容遗漏

- [ ] 客户点名要去的景点，是否真的写进去了？
- [ ] 客户给的具体信息（价格、班次、餐厅名、拍照机位、酒店）有没有漏？

### 7. 确认过的变量未生效

- [ ] 客户说"顺序改成 A→B→C"，写出来是不是 A→C→B？
- [ ] 客户说"加一个 XX"，有没有忘？
- [ ] 人数、交通、出发时间、住宿是否在**所有相关行**都一致？还是只改了标题、正文仍是旧的？

### 8. 擅自添加

- [ ] 客户说"下午自由活动"，AI 有没有自己塞进国家美术馆？
- [ ] 客户标的"可选"，有没有被写成必去？
- [ ] 有没有重复安排前几天已经去过的景点？

## 每天完成后的快速勾选

- [ ] **第一行是当天起点**（落地／退房／从酒店出发），不是直接跳到第一个景点
- [ ] **最后一行写了回酒店**
- [ ] **每段移动都写了怎么走**（交通方式、耗时、票价，景点之间没有断层）
- [ ] 日期和星期正确
- [ ] 人数及儿童年龄正确
- [ ] 固定时间与客户截图一致
- [ ] 开放时间允许入内（当天不闭馆）
- [ ] 午餐和晚餐都在
- [ ] 路线无明显折返
- [ ] 酒店入住／寄存表述正确
- [ ] 无旧客户信息残留
- [ ] 无重复景点
- [ ] 可选与必去区分明确
- [ ] 客户新增要求全部落实
- [ ] `●` 分点和详细备注保留
- [ ] 文件里没有内部备注（"沿用模板""参考了XX"之类）

> 怎么做见《[制作指南](制作指南.md)》，这一页只管检查。

## 出稿后（工具查不出来的）

`拼行程.py` 会自动查时间倒流、时段重复、旧客户信息残留。以下要人眼过：

- [ ] 每天第一行是当天起点，不是直接跳到第一个景点
- [ ] 段与段之间没有断层，每次移动都写了怎么走
- [ ] 抵达日有取行李、进城、入住的行
- [ ] 首行的来源城市是本单的，不是上一位客户的
- [ ] 入内项目与客户要求一致
- [ ] 日落时间和季节描述已按本单月份改过
- [ ] 每天最后写了回酒店
- [ ] 图片数与模板一致（为 0 说明内容被重打了）
- [ ] 表格之间有空段，没有黏成一张

## 欧洲订单再加

- [ ] 跨城车次的出发站名写全了？（威尼斯 Santa Lucia 还是 Mestre／哪个巴黎站）
- [ ] 需要打卡激活的车票，备注里写了？
- [ ] 落在周日／周一的市场和博物馆，营业状态查过了？
- [ ] 预约项目的提前期够不够？（斗兽场 30 天、《最后的晚餐》2 个月）
- [ ] 宗教场所着装提醒写了？
- [ ] 山区／海岛项目有天气替代方案？
- [ ] 涉及瑞士的行程，退税盖戳提醒写了？
