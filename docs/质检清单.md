# 交付质检清单

## AI 最容易犯的 8 类错误

### 1. 时间错误

- 固定班次、航班、演出或预约时间是否与客户截图一致？
- 是否默认安排得过早？
- 午餐和晚餐是否遗漏？
- 是否把寄存行李误写成提前入住？
- 是否把闭馆时间误认为最后入场时间？

### 2. 人数错误

- 是否残留原模板人数？
- 成人、儿童数量是否正确？
- 儿童年龄限制是否落实，并提供不能参加时的替代方案？

### 3. 擅自精简

- `●` 分点是否保留？
- 景点详细说明是否无故删除？
- 餐厅、美食清单、停车、咖啡厅和洗手间说明是否误删？

### 4. 顺序错误

- 是否遵守已确认的新顺序？
- 模板顺序是否与开放时间冲突？
- 一天内是否出现明显折返？

### 5. 格式错误

- 是否仍为四列表格？
- 分点是否乱码？
- 时间格式是否统一？

### 6. 新增内容遗漏

- 客户新增的景点是否真正写入？
- 客户提供的价格、班次、餐厅、酒店和机位是否遗漏？

### 7. 已确认变量未生效

- 人数、顺序、交通、出发时间、住宿是否在所有相关行中一致？
- 是否只改了标题，正文仍残留旧信息？

### 8. 重复与可选项误判

- 是否重复安排前几天已参观的景点？
- “自由活动”是否被自动填入已去过景点？
- 可选景点是否误写成必去？

## 每天完成后的快速检查

- [ ] 日期和星期正确。
- [ ] 人数及年龄正确。
- [ ] 固定时间正确。
- [ ] 开放时间允许入内。
- [ ] 午餐和晚餐存在。
- [ ] 路线无明显折返。
- [ ] 酒店入住与寄存表述正确。
- [ ] 无旧客户信息残留。
- [ ] 无重复景点。
- [ ] 可选与必去区分明确。
- [ ] 新增要求全部落实。
- [ ] `●` 分点和详细备注保留。
