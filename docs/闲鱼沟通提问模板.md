# 闲鱼沟通提问模板

## 客户信息较模糊时

您好，为了给您安排更顺路、也更符合实际开放时间的行程，麻烦确认以下信息：

1. 往返日期、机场和航班时间是什么？
2. 一共几位成人、几位儿童？儿童分别几岁？
3. 已确定必须去的城市和景点有哪些？
4. 哪些景点只是备选，哪些明确不想去？
5. 更偏好火车、自驾还是包车？如果自驾，计划哪天取车和还车？
6. 酒店是否已经预订？如果已订，请提供城市、区域和入住日期。
7. 每天希望大约几点出发？喜欢轻松还是紧凑的节奏？
8. 是否有老人、儿童、行动不便、饮食忌口或其他特殊需求？
9. 是否有音乐剧、球赛、餐厅或景点预约等固定时间？

## 客户已有路线草稿时

收到，我会先核对日期、星期、景点闭馆日和城市动线。为了避免后续详细行程反复修改，还需要确认：

- 路线中的景点都是必去，还是包含可选项？
- 城市和住宿是否已经不能调整？
- 固定交通及预约是否已经付款？
- 是否接受根据开放时间调整上午、下午和晚上的顺序？
- 是否有不希望重复安排的景点？

## 框架确认话术

这是根据您的日期、人数、交通方式和必去景点整理的初步框架。当前先确认城市顺序和每天的大致内容，详细开放时间、交通步骤、餐厅及注意事项会在框架确认后逐日补充。上午／下午的顺序可能会根据景点开放时间和实际动线微调。
