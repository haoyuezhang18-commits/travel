# 成品参考定位：先看做完的长什么样

骨架告诉你**有哪些格子**，成品告诉你**每个格子该填到什么颗粒度**。交付前先看一份同类成品，比照着空模板猜准得多。

> ⚠ 这些是**真实客户成品**。只看格式、结构和写作颗粒度，**客户的日期、人数、酒店、航班号一律不得抄进新订单**。仓库里只存路径，不存内容。

## 怎么看

```bash
python3 tools/看成品.py --list              # 有哪些可参考的
python3 tools/看成品.py 英国15天             # 看结构：每日一行概述 + 每天标题 + 表头 + 行数
python3 tools/看成品.py 英国15天 --day 3     # 完整打印第3天，看备注写到什么程度
python3 tools/看成品.py 票务与预约 --day 1   # 文档2 同理，按表序号
```

先看结构大纲（几十行），确认这份值得参考，再 `--day` 深入看某一天。**不要整份读进上下文**，长线成品有 3 万多字。

## 从成品里学到的几条写法

这些是空骨架体现不出来、只有看成品才知道的：

1. **概述行要含航班号和住宿地**。不只是景点罗列，落地日写航班和进城方式，转场日写"住XX"。
2. **购票方式两条腿走**：官网链接 + 国内平台搜索词。客户按自己习惯选，不用你判断。
3. **免费景点也要进汇总表**，写"免费无需预约"，客户才知道这项不用操心，而不是以为你漏了。
4. **备注写到可执行**：不是"注意防盗"，而是"这里是罗马第一偷盗重灾区，包必须背在胸前"。
5. **同城连续景点的城市列留空**，只在换城时写，表格更清爽。
6. **住宿按晚数写**（`9/24-9/30（6晚）`），客户一眼能核对总晚数对不对。

## 交付前对照

- 我的概述行有没有做到"日期＋周几＋主线＋住哪"？
- 我的备注是不是停留在"注意安全"这种没法执行的层面？
- 文档2 里免费景点写了吗？购票方式给了国内平台吗？
- 住宿有没有写晚数？
