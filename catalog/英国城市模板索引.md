## 各模板默认路线

### 伦敦

详细城市页：[`cities/uk/london.md`](../cities/uk/london.md)

模板包含多套路线，不应整份读取后直接拼接。常用组合：

- 抵达：机场取行李 → 交通／办卡 → 酒店 → 深夜觅食。
- 西敏经典线：白金汉宫 → 圣詹姆斯公园 → 唐宁街／白厅 → 威斯敏斯特教堂 → 大本钟／伦敦眼 → 塔桥。
- 博物馆购物线：大英博物馆 → 午餐 → 科文特花园 → 国家美术馆／特拉法加广场 → 摄政街／牛津街 → Soho晚餐。
- 泰晤士河南岸线：圣保罗大教堂 → 千禧桥 → 博罗市场 → 泰特现代 → 塔桥 → 碎片大厦。
- 福尔摩斯主题线：酒店 → 贝克街221B → 福尔摩斯酒吧 → 特拉法加广场 → 摄政街 → Soho。

使用提醒：先按开放时间选择路线，不要将13套路线全部视为可同时使用。

### 剑桥

默认路线：伦敦国王十字 → 剑桥 → 菲茨威廉博物馆 → 数学桥／圣体钟 → 午餐 → 康河撑篙 → 牛顿苹果树 → 市集广场 → 晚餐 → 返回伦敦。

适用变化：自驾抵达或住剑桥时，删除火车、Railcard和返伦敦段；菲茨威廉通常周一闭馆，必须核对。

### 苏格兰高地／天空岛／威士忌产区

第一段：格拉斯哥 → 罗蒙湖Luss → Skyfall拍摄地 → Lagangarbh小白房 → 三姐妹山 → 格伦芬南高架桥 → 威廉堡入住。

第二段：威廉堡 → 爱莲朵娜城堡 → 斯凯桥 → 波特里 → 老人峰 → 波特里住宿。

第三段：波特里 → 尼斯湖 → 达夫镇 → 威士忌酒厂 → 斯佩塞小镇。

使用提醒：文件名仍为“天空岛2天”，但实际包含3张日程表。制作前必须确认威廉堡、波特里、达夫镇等具体住宿位置，不得只写“住高地”。

### 温德米尔／湖区

- 抵达休闲版：抵达温德米尔 → 入住／码头午餐 → 游船 → 彼得兔 → 小镇 → 晚餐。
- 小镇版：温德米尔 → Ambleside → Grasmere → 姜饼屋 → Dove Cottage → 返回。
- 徒步版：Ambleside → White Moss → Rydal Cave环线 → Grasmere午餐／姜饼屋／Dove Cottage。
- 游船＋蒸汽火车版：曼彻斯特 → 温德米尔／Bowness → 游船至Lakeside → 蒸汽火车往返Haverthwaite → 彼得兔 → Bowness晚餐。

已知问题：游船＋蒸汽火车版把“曼彻斯特站→温德米尔站”和“火车上”拆成两行，实际属于同一段跨城交通。调用时应按真实班次合并并重写。

### 爱丁堡

- 经典全天版：爱丁堡城堡 → 维多利亚街 → 大象咖啡馆 → 午餐 → Bobby → 皇家一英里 → 爱丁堡大学 → 国立博物馆 → 购物 → 晚餐 → 卡尔顿山。
- 精简一日版：维多利亚街 → 咖啡馆 → Bobby → 博物馆 → 大学 → 午餐 → 城堡 → 皇家一英里。
- 夜巴抵达版：大巴站 → 寄存行李 → 早餐 → 王子街 → 城堡 → 维多利亚街 → 皇家一英里 → 博物馆 → 卡尔顿山。
- 荷里路德宫版：荷里路德宫 → 午餐 → Dean Village → Water of Leith → Stockbridge。

适用变化：住牛津或自驾抵达时删除往返火车段。

### 布莱顿＋七姐妹白崖

默认路线：Victoria → Brighton → 英皇阁 → 布莱顿码头／午餐 → 公交至七姐妹 → Coastguard Cottages → Birling Gap → Belle Tout → Beachy Head → Eastbourne → 返回伦敦。

使用提醒：徒步强度、天气、风力和日落时间必须考虑；不要把多段徒步写得过轻松。

### 七姐妹白崖自驾版

默认路线：牛津退房 → South Hill Barn → 白房子机位 → Birling Gap午餐／海滩 → Belle Tout → Beachy Head → 晚餐 → 伦敦还车／入住。

### 坎特伯雷＋七姐妹白崖

默认路线：伦敦St Pancras → Canterbury West → Westgate Gardens → 坎特伯雷撑篙 → 大教堂／书店／歪房子外观 → Eastbourne → 七姐妹白崖徒步 → 晚餐 → 伦敦Victoria。

已知问题：

- 候车段08:40结束，但模板列车09:40才出发，中间1小时未解释。
- 撑篙结束后只给大教堂、书店和歪房子约20分钟，明显偏紧。
- 从大教堂区域到Canterbury West只预留3分钟，不现实。
- 列车班次必须按客户日期重新查询，不得沿用模板时间。

调用原则：保留“坎特伯雷在前、白崖在后”的城市顺序，但整天时间轴必须重算。

### 科茨沃尔德

第一天：牛津／其他城市出发 → Bourton-on-the-Water寄存行李 → 水上伯顿 → 午餐 → 模型村及小镇景点 → 自由活动 → 晚餐。

第二天：Bourton → Bibury → 午餐 → Castle Combe → 下午茶 → 返回Bourton。

使用提醒：模板混合“包车／公共交通”写法。新客户自驾时，应统一为自驾并补充停车；如果不住Bourton，应按住宿位置重排。

### 福尔摩斯

默认路线：希思罗抵达 → 酒店 → Brunch → 贝克街221B → 福尔摩斯酒吧 → 特拉法加广场 → 摄政街 → Soho晚餐。

### 约克

默认路线：火车抵达 → 酒店寄存行李 → 国家铁路博物馆 → 午餐 → 古城墙 → 约克大教堂 → 肉铺街 → 克利福德塔／地牢 → 城堡博物馆 → 晚餐 → 乌斯河夜景。

已知问题：原模板把克利福德塔和城堡博物馆排得过晚。制作时优先保证大教堂最后入场，并把城堡博物馆安排在闭馆前或删除；城墙9月中下旬关闭较早。

### 达西庄园

默认路线：约克 → 谢菲尔德 → 庄园入口 → House内部 → 午餐 → Garden／缆车 → 入住。
