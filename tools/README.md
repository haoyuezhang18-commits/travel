# tools

## 取路线.py（日常用这个）

按路线编号，只取出本地 DOCX 里的那一张表，不通读整份文件。

```bash
python3 tools/取路线.py LAK-R03        # 输出这条路线的四列表格
python3 tools/取路线.py --list 卡普里   # 按关键词反查编号
python3 tools/取路线.py ROM-R02 --root /别的路径/旅游通用模板
```

模板根目录查找顺序：`--root` 参数 → `config/local-paths.yaml` 的 `template_root` → `~/文件夹/旅游通用模板`。

依赖：`pip install python-docx`

## 看成品.py（交付前看一眼做完的效果）

```bash
python3 tools/看成品.py --list              # 有哪些可参考的成品
python3 tools/看成品.py 英国15天             # 结构大纲：概述 + 每天标题 + 表头
python3 tools/看成品.py 英国15天 --day 3     # 完整打印第3天，看备注颗粒度
```

先看大纲再 `--day` 深入，**不要整份读进上下文**（长线成品 3 万多字）。参考清单在 `catalog/成品参考.csv`，说明在 `catalog/成品参考定位.md`。

⚠ 这些是真实客户成品，只看格式，客户信息不得抄进新订单。

## 打标.py（加了新模板才用）

给本地 DOCX 打路线编号标签：每张表前插入 `【编号】路线名`，多版本文件顶部插入本文件路线索引。**已打过标的会自动跳过，可以重复运行。**

新增模板或新增版本时：

1. 在 `tools/mapping.py` 里补上 `文件路径 → [(编号, 路线名), ...]`，顺序必须与文件里表格的实际顺序一致。
2. 空跑校验表数是否对得上。
3. 运行 `python3 tools/打标.py`。
4. 重新生成 `catalog/路线定位表.csv`。
5. 在对应城市页加上这条路线。

**动手前先备份整个模板库**——这个脚本会直接改写 DOCX。

## mapping.py

编号与表格顺序的对照表，`打标.py` 和定位表都从它生成。改模板结构后要同步更新。
