# 英国／欧洲定制旅行交付知识库

本仓库用于让任何新接手的 AI 或人工协作者，在不了解历史聊天的情况下，快速掌握完整工作流、模板库内容、交付标准和质检要求。

## 新 AI 从这里开始

请按顺序阅读：

1. [`AI_START_HERE.md`](AI_START_HERE.md)：身份、目标、绝对规则与工作顺序。
2. [`docs/完整交付SOP.md`](docs/完整交付SOP.md)：从闲鱼沟通到最终交付的全过程。
3. [`docs/逐日制作规则.md`](docs/逐日制作规则.md)：最耗时的逐日详细行程如何制作。
4. [`docs/质检清单.md`](docs/质检清单.md)：交付前逐项检查。
5. [`catalog/英国城市模板索引.md`](catalog/英国城市模板索引.md)：本地已有的城市模板及默认路线。
6. [`docs/知识库更新规则.md`](docs/知识库更新规则.md)：完成订单后如何沉淀新模板与经验。

## 知识库保存什么

- 完整业务工作流与客户沟通规则。
- 客户需求变量及其优先级。
- 城市模板索引和默认游览路线摘要。
- AI 常见错误、闭馆冲突、格式规则和最终检查项。
- 可跨账号、跨 AI 使用的接手提示词。

## 不保存什么

- 客户姓名、电话、订单号、身份证件、机票票号等隐私信息。
- 每位客户的完整原始聊天记录。
- 大量客户成品 DOCX、PDF 和图片。
- 会随电脑变化的绝对路径。绝对路径仅放在本地配置文件中。

## 原始文件与本仓库的关系

- 原始 DOCX、PDF、图片继续保存在本地“旅游通用模板”文件夹。
- 本仓库保存可检索的文字摘要、规则和索引。
- 制作具体城市时，先读本仓库资料卡；真正开始填充当天内容时，再打开对应原始 DOCX。
