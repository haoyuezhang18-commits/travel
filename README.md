# 英国／欧洲定制旅行交付知识库

本仓库用于让任何新接手的 AI 或人工协作者，在不了解历史聊天的情况下，快速掌握完整工作流、模板库内容、交付标准和质检要求。

## 新 AI 从这里开始

**先读这三份**（做任何订单都要）：

1. [`AI_START_HERE.md`](AI_START_HERE.md)：身份、目标、开工要点
2. [`docs/铁律.md`](docs/铁律.md)：**唯一的规则来源**。时间、变量、内容、口吻、格式、核对、优先级
3. [`docs/制作指南.md`](docs/制作指南.md)：**怎么做**。排框架 → 做逐日 → 出稿 → 交付，含选模板、保姆级标准、变量替换、出稿核对

**做的过程中查**：

4. [`docs/完整交付SOP.md`](docs/完整交付SOP.md)：六步全流程（第一步和第三步由负责人做）
5. [`docs/质检清单.md`](docs/质检清单.md)：交付前逐项检查
6. [`catalog/英国城市模板索引.md`](catalog/英国城市模板索引.md) / [`catalog/欧洲城市模板索引.md`](catalog/欧洲城市模板索引.md)：城市页跳转表
7. [`catalog/路线定位表.csv`](catalog/路线定位表.csv)：174 条路线的编号 → 模板文件 → 第几张表 → 图片数
8. [`docs/客户变量表模板.md`](docs/客户变量表模板.md)：新订单先建这张表

**做欧洲订单额外读**：

9. [`docs/欧洲通用避坑规则.md`](docs/欧洲通用避坑规则.md)：跨国交通、票务激活、退税、周日关门

**交付阶段**：

10. [`templates/`](templates/)：框架（给客户看的两种格式）、文档1、文档2 的骨架
11. [`catalog/成品参考定位.md`](catalog/成品参考定位.md)：交付前看一份做完的成品对照颗粒度

**订单结束后**：

12. [`docs/知识库更新规则.md`](docs/知识库更新规则.md)：如何沉淀新模板与经验

## 知识库保存什么

- 完整业务工作流。
- 客户需求变量及其优先级。
- 城市模板索引和默认游览路线摘要。
- AI 常见错误、闭馆冲突、格式规则和最终检查项。
- 可跨账号、跨 AI 使用的接手提示词。

## 不保存什么

- 客户姓名、电话、订单号、身份证件、机票票号等隐私信息。
- 每位客户的完整原始聊天记录。
- **闲鱼沟通话术**。客户沟通是负责人的工作，不属于 AI 知识库。
- 大量客户成品 DOCX、PDF 和图片。
- 会随电脑变化的绝对路径。绝对路径仅放在本地配置文件中。

## 原始文件与本仓库的关系

- 原始 DOCX、PDF、图片继续保存在本地“旅游通用模板”文件夹（英国在“英国旅游通用模板”下，欧洲在“欧洲”下按西欧／中欧／南欧／北欧分区）。
- 本仓库保存可检索的文字摘要、规则和索引。
- 制作具体城市时，先读本仓库城市页选定编号路线；填充当天内容时用 `python3 tools/取路线.py <编号>` 只取那一张表。
- 本地 DOCX 已按路线编号打好标签（每张表前一行 `【编号】名称`，多版本文件顶部有本文件路线索引），WPS 里 Ctrl+F 搜编号即可跳转。
