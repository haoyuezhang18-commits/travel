## 现有成熟路线

### BUD-R01 佩斯侧（抵达日）

核心景点：中央市场、自由桥、国家歌剧院、自由广场、国会大厦。

```text
08:05-09:30 落地、出关＋取行李
→ 09:30-10:30 机场至市区
→ 10:30-11:30 办理入住／寄存行李
→ 11:30-13:30 中央市场（Great Market Hall）
→ 13:30-14:30 自由桥（Liberty Bridge）拍照
→ 14:30-16:30 匈牙利国家歌剧院
→ 16:30-18:00 自由广场＋国会大厦打卡
→ 18:00-20:00 晚餐深度体验
```

调序规则：

- 中央市场是"迷你义乌"，买明信片和冰箱贴的地方；午餐在市场二层 Langos 摊位（炸油饼配芝士和酸奶）。
- 歌剧院选演出场（19:00）时，下午 14:30–16:30 要另填内容，晚餐必须提前到 17:00–18:30。
- 晚餐 3 选 1（5区核心）：Hungarikum Bisztró（4.8分／£25–35，全城最火，**需提前一周预订**，必点脆皮烤鸭）等。
- 模板末尾有"全天通用 Tips：交通、支付与时差"一段，可直接复用。

### BUD-R02 布达侧（城堡区日）

```text
07:00-09:00 渔人堡（日出／晨光）
→ 09:00-11:00 布达城堡区深度游
→ 11:00-13:00 城堡区午餐
→ 13:00-15:30 链桥与电车捕捉
→ 15:30-17:30 纽约咖啡馆
→ 17:30-19:00 圣伊什特万圣殿
→ 19:00-21:00 多瑙河游船（夜游）
```

调序规则：

- **07:00 到渔人堡是为了避开人潮拍晨光**，这是这条线的核心设计。客户不愿早起时，渔人堡要改到傍晚（金色时刻），并把游船提前。
- 日落时间按月份查：9月约19:15。多瑙河夜游必须排在天黑之后，日落时间变了整条线尾部都要跟着动。
- 圣伊什特万圣殿学生票 1800 HUF；很多景点有联票（如渔人堡＋马加什教堂）。
