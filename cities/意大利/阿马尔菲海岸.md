## 现有成熟路线

### SOR-R01 罗马→索伦托抵达日

核心景点：塔索广场、悬崖公路、圣凯撒略街、市政别墅花园、Marina Grande 海滩。

```text
08:30-09:30 罗马退房→车站
→ 10:00-11:12 罗马→拿坡里（建议提前在 App 买票）
→ 11:30-12:45 换乘私铁→索伦托
→ 13:00-14:00 酒店寄存
→ 14:00-15:00 午餐：老城简餐
→ 15:30-17:00 圣凯撒略街深度采购
→ 17:00-18:00 市政别墅花园（Villa Comunale）
→ 18:00-19:30 Marina Grande 海滩漫步
→ 19:30 以后 晚餐：Porta Marina
```

调序规则：

- 已知问题：模板里 `13:00–14:00 午餐` 与 `13:00–15:30 塔索广场→悬崖公路` **时间完全重叠**。调用时重排（建议：寄存→塔索广场＋悬崖公路→午餐→圣凯撒略街）。
- 餐厅：Storico8 Pizza in teglia（千层面和披萨，人均€20–30，**不接受预约和外带，需现场排队**）；Fresco Sorrento 吃现打柠檬冰沙。

### SOR-R02 波西塔诺＋阿马尔菲一日（SITA 巴士）

两个版本内容基本相同，第二版的购票操作说明更细，**优先用第二版**。

```text
08:30-09:15 早餐＋前往索伦托火车站门口的 SITA 大巴站（09:15 前必须到）
→ 09:15-09:30 买票＋排队
→ 09:30-10:45 索伦托→波西塔诺（SITA 巴士约60分钟）
→ 10:45-13:00 波西塔诺（Positano）沿途机位打卡
→ 13:00-13:40 波西塔诺→阿马尔菲
→ 13:40-15:30 阿马尔菲（Amalfi）午餐
→ 15:30-16:30 主街小巷与海边闲逛
→ 16:30-16:45 路边小吃
→ 16:45-18:00 阿马尔菲→返回索伦托
→ 18:30-20:30 索伦托老城晚餐
```

调序规则：

- **去程必须坐行车方向右侧**（窗外是悬崖大海），从阿马尔菲返回索伦托坐**左侧**；晕车提前吃药。
- 到波西塔诺前会在阿马尔菲停靠换乘，**没有固定车次**，看到 SITA 去波西塔诺的车就能上，上车前问清楚；第二程会检票，票要收好。
- 旺季返程排队人数极多，**务必提前15–20分钟到车站卡位**，注意末班车。
- 返程也可选船（模板写"坐车/船回索伦托"），船受海况影响，要写替代方案。
- 晚餐那家很有名，没预约要早点去排队。

### SOR-R03 卡普里岛（蓝洞优先版）

```text
08:30-09:15 早餐＋前往港口
→ 09:15-09:45 买票＋确认蓝洞状态
→ 09:45-10:15 乘船前往卡普里岛
→ 10:15-12:00 蓝洞（Grotta Azzurra）
→ 12:00-13:30 登顶 Anacapri
→ 13:30-14:30 Anacapri 午餐
→ 14:30-16:30 Capri 小镇＆奥古斯都花园
```

调序规则：

- **只买去程单程票，时间更灵活。**
- 已知问题：**这一版 16:30 结束后没有返程段**，调用时必须自行补上回索伦托的船（约45分钟）和晚餐。

### SOR-R04 卡普里岛（Anacapri 优先＋转罗马版）

```text
08:30-09:30 出发前往港口
→ 09:45-10:15 乘船前往卡普里岛
→ 10:30-13:00 Capri 小镇＆奥古斯都花园
→ 13:00-14:30 名流街午餐＋自由活动
→ 14:30-15:00 Capri 小镇→下山回码头
→ 15:15-16:00 乘船返回索伦托（轮渡约45分钟）
→ 16:30-18:30 索伦托→拿坡里→罗马
→ 19:00 以后 抵达罗马→晚餐／入住
```

调序规则：

- 这一版**放弃蓝洞**，换取当天能赶回罗马。适合最后一天。
- 时间很紧：15:15 的船、16:30 的火车中间只有30分钟，行李必须提前寄存在索伦托车站或酒店。

### SOR-R05 卡普里岛（双方案版）

模板给了两条并行路径，下午在奥古斯都花园汇合：

- **方案一**：大码头直接坐接驳船去蓝洞（适合不愿折腾），车程5分钟但旺季排队20–30分钟 → 午餐＆逛街 → 奥古斯都花园。
- **方案二**：坐岛上小巴去蓝洞（排队相对快、性价比高）→ 安卡普里→索拉罗山单人吊椅缆车 → 奥古斯都花园。

```text
08:30-09:30 出发前往港口
→ 09:45-10:15 乘船前往卡普里岛
→ 10:15-13:00 方案一或方案二（二选一）
→ 13:00-15:30 方案二：索拉罗山缆车／方案一：午餐＆逛街
→ 15:30-17:00 汇合：卡普里小镇→奥古斯都花园（打卡发夹弯）
→ 17:15-18:00 乘船返回索伦托
→ 18:00 以后 索伦托酒店→老城晚餐
```

调序规则：

- **这是三个卡普里版本里最完整的一版**（有返程、有替代方案、有分支）。优先用它。
- 出发前务必在官网或 Info Grotta Azzurra 的 Facebook 主页确认当天蓝洞是否开放。
- 选方案二并想坐完缆车去大码头的，注意下山巴士末班约16:00。
