## 现有成熟路线

### FLR-R01 罗马抵达日（半日精华）

```text
罗马Termini→佛罗伦萨SMN（高铁约1.5h）
→ 酒店存行李
→ 中央市场（Mercato Centrale）
→ 午餐
→ 学院美术馆（外观路过）
→ 圣母百花大教堂（外观拍照）
→ 共和广场
→ 旧宫／领主广场
→ 乌菲兹美术馆（16:00预约，2h45m）
→ 老桥
→ 剪影机位＋米开朗基罗广场日落
→ Oltrarno区晚餐
```

调序规则：

- 乌菲兹二楼重点：A11《春》、A12《维纳斯的诞生》（波提切利）、A35《天使报喜》《三王来朝》（达芬奇）、A38《圣家族》（米开朗基罗）、A38《金翅雀圣母》（拉斐尔）；一楼：C1拉斐尔《自画像》、D23提香《乌尔比诺的维纳斯》。这份路线图可以直接写进客户备注。
- 日落剪影机位在去米开朗基罗广场之前，定位 Piazzale Michelangelo, 50125 Florence，在靠山边的马路边上，**不留神容易错过**。最佳时间是日落前1小时（暖金色）和日落后10–20分钟的蓝调时刻。
- 学院美术馆这一版只安排外观（周一闭馆、行程紧）；客户明确要看《大卫》时必须预约并挪出1.5–2小时。

### FLR-R04 转场威尼斯日（皮蒂宫上午版）

```text
退房寄存行李
→ 09:50-10:00 皮蒂宫排队入场
→ 10:00-12:00 皮蒂宫
→ 波波里花园
→ Oltrarno区午餐
→ 回酒店取行李→SMN站
→ 15:00-16:15 候车＋买票＋找站台
→ 16:20-18:34 Frecciarossa至威尼斯Santa Lucia
→ 酒店入住＋晚餐
→ 圣马可广场夜景
```

调序规则：

- 皮蒂宫必看：帕拉蒂娜画廊（拉斐尔、提香、鲁本斯、凡·戴克真迹）、皇家寓所；现代艺术画廊和服饰博物馆时间紧可跳过。
- **车票不要拖到出发前几分钟买，票价会暴涨。** 购票：Trenitalia官网／Trainline App／携程／自助售票机。
- 大屏幕提前10–15分钟公布站台；**火车出发前5分钟停止检票**。
- 到威尼斯要下 **Santa Lucia站（主岛）**，不是Mestre站。
- 已知问题：模板里同一段车程写了 `16:20–18:34` 和 `16:00–18:30` 两个版本，班次必须按客户日期重查。
