# 蔚蓝海岸模板索引（尼斯／昂蒂布／戛纳／摩纳哥／埃兹／芒通）

## 区域信息

- 区域：法国蔚蓝海岸（Côte d'Azur）
- 区域编号：CDA
- 原始模板：
  - `法国/尼斯/法国尼斯通用版本.docx`（1张表）
  - `法国/尼斯一昂蒂布一戛纳/尼斯一昂蒂布一戛纳.docx`（1张表）
  - `法国/摩纳哥-芒通一埃兹小镇/摩纳哥-芒通一埃兹小镇.docx`（1张表）
- 合并成一页的原因：三份模板全部以**尼斯为base**，向西（昂蒂布/戛纳）和向东（埃兹/摩纳哥/芒通）各一条，加上尼斯城内一条。客户住尼斯几晚就配几条，不需要分开读三份。

## 现有成熟路线

### CDA-R01 尼斯城内（巴黎当日往返版）

```text
07:00-12:30 巴黎→尼斯（TGV）
→ 12:30-13:00 尼斯火车站→圣母圣殿
→ 13:00-13:30 梅德森大道（商业街）
→ 13:30-14:30 午餐
→ 14:30-15:00 马塞那广场（Masséna）
→ 15:00-15:45 萨雷亚集市（Cours Saleya）
→ 15:45-16:00 尼斯老城（迷宫小巷）
→ 16:00-17:15 城堡山（电梯上山）
→ 17:15-18:00 I LOVE NICE 地标
→ 18:00-18:30 英国人散步大道→蓝滩
→ 18:30-19:30 晚餐
→ 20:45+ 尼斯→巴黎（TGV，坐前进方向左侧）
```

调序规则：

- 这是**单日极限往返**，去程5.5小时、返程近深夜，实际游玩仅约8小时。客户住尼斯时**必须删掉首尾两段TGV**，把景点摊开成轻松半日或一日。
- **萨雷亚集市要核对星期**：周二至周日是鲜花水果，周一是 vintage，下午13:00收摊（有的店晚上五六点还在）。排在下午的必须确认当天状态。
- 城堡山有电梯，但山上风很大，拍照注意手机。
- 尼斯站周边注意看管随身物品。

### CDA-R02 西线：昂蒂布＋戛纳（火车串联）

```text
09:00-09:15 酒店→尼斯火车站
→ 09:15-09:30 候车＋买票
→ 09:38-09:59 尼斯（Nice-Ville）→昂蒂布（Antibes）
→ 10:00-11:30 昂蒂布老城
→ 12:18-12:26 昂蒂布→戛纳（Cannes）
→ 12:35-13:35 戛纳午餐
→ 13:35-16:00 戛纳：影节宫＋克鲁瓦塞特大道
→ 16:36-17:05 戛纳→尼斯
→ 18:30-20:00 尼斯晚餐
```

调序规则：

- 班次密集（约每30分钟一班），随到随买。**但模板写死的班次必须按客户日期在 SNCF Connect 重查。**
- 购票四渠道：SNCF Connect App／Trainline（中文）／携程／车站自助售票机。
- 影节宫大厅可免费进入参观（有活动则关闭），门口有明星手印和红毯台阶。
- 昂蒂布只给1.5小时，客户想看毕加索博物馆要另加1小时，相应压缩戛纳。

### CDA-R03 东线：埃兹＋摩纳哥＋芒通（包车）

```text
09:00-09:30 尼斯→埃兹
→ 09:30-11:30 埃兹小镇（Èze Village）
→ 11:30-12:10 埃兹→摩纳哥
→ 12:10-13:10 摩纳哥午餐
→ 13:10-14:30 摩纳哥：亲王宫、海洋博物馆、赌场、港口
→ 14:30-15:10 摩纳哥→芒通（Menton）
→ 15:10-16:30 芒通
→ 16:30-18:00 芒通→尼斯（沿滨海公路，傍晚光线好，可拍日落海岸线）
→ 18:00-18:30 回酒店休整
→ 18:30-20:30 尼斯晚餐
```

调序规则：

- **全程包车**（每段30–50分钟）。改火车或公交必须重算：埃兹火车站在海边，到山顶村还要爬坡或转公交，至少多留40分钟。
- 摩纳哥亲王宫换岗仪式在 11:55，模板自己就注明"可能赶不上，看当天节奏"——**不要写成必看**，写成"（可选）"。
- 亲王宫门票约€10/人，可参观皇家公寓和武器收藏；宫殿广场可俯瞰摩纳哥港口全景。

## 三条线共用的晚餐推荐

**注意：R01 和 R03 的晚餐推荐完全一样**（Le Galet 海边露台／Boccaccio 生蚝海鲜饭／La Vague 法餐，人均€30–40，均需提前预约）。客户在尼斯住多晚时，**不要每天推荐同一批餐厅**，第二天起要另找。

## 改这天要动哪几行

## AI 调用规则

1. 先确定**住哪里、住几晚**：住尼斯是常态，三条线按天分配。
2. 三条线互不重叠，可以自由组合，但同一订单不要重复推荐同一批餐厅。
3. 所有火车班次必须按客户日期重查，模板里的分钟级时刻是某次订单的产物。
4. 摩纳哥换岗、萨雷亚集市这类"当天才知道"的项目一律写成"（可选）"。
