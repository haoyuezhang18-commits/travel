- 城市：柏林

## 现有成熟路线

### BER-R01 慕尼黑抵达日（半日）

```text
09:50-10:00 酒店→慕尼黑中央火车站
→ 10:22-14:22 慕尼黑→柏林（ICE 约4小时）
→ 14:30 抵达柏林中央火车站
→ 14:30-15:30 酒店入住＋放行李＋买交通票
→ 15:30-16:30 东边画廊附近餐厅
→ 16:30-17:00 东边画廊（East Side Gallery）
→ 17:00-18:00 Marheineke 市场
→ 19:30-20:30 夜游哈克市场
→ 20:30-21:00 返回酒店
```

调序规则：

- 午餐在火车站超市提前买好，车上吃三明治省时（4小时车程）。
- **东边画廊沿街小贩的"柏林墙碎片"是假的**，纪念品去正规店买。
- 哈克市场核心亮点是 Haus Schwarzenberg 涂鸦庭院（Rosenthaler Str. 39 入口，5层楼全是涂鸦），但人少时建议外面看看就好，注意安全。
- 已知问题：`18:00–19:30` 有1.5小时空档没有内容，调用时补上（建议插入晚餐）。

### BER-R02 冷战／政治线（Day1）

核心景点：国会大厦、勃兰登堡门、大屠杀纪念碑、波茨坦广场、查理检查哨、柏林墙纪念馆、托普秘密地下世界、菩提树下大街。

```text
09:00-09:30 前往国会大厦
→ 09:30-10:30 国会大厦＋玻璃穹顶
→ 10:30-11:15 勃兰登堡门＋周边
→ 11:15-11:45 犹太人大屠杀纪念碑
→ 11:45-12:30 波茨坦广场
→ 12:30-13:30 午餐（波茨坦广场周边）
→ 13:30-14:30 查理检查哨
→ 14:30-15:00 柏林墙纪念馆（备选）
→ 15:00-15:30 托普秘密地下世界（备选）
→ 15:30-17:00 菩提树下大街漫步
→ 17:00-18:30 自由活动＋购物
→ 18:30-20:00 晚餐
```

调序规则：

- 国会大厦预约时间决定整天起点，模板给的地铁路线：酒店步行3分钟到 Heinrich-Heine-Straße，U8 两站到 Alexanderplatz，换 U5 五站到 Bundestag，步行4分钟。**客户酒店不同时这段全部重写。**
- 勃兰登堡门周日游客很多，早点到人少。
- 两个"备选"各只给30分钟，实际上柏林墙纪念馆和托普展览各需1–1.5小时。**要进就得砍掉后面的购物时段**，不能照抄。

### BER-R03 博物馆岛线（Day2）

```text
09:00-09:30 前往柏林大教堂
→ 09:30-10:30 柏林大教堂（Berliner Dom）
→ 10:30-13:30 博物馆岛（Museumsinsel）
→ 13:30-14:30 午餐（博物馆岛周边）
→ 14:30-16:00 亚历山大广场
→ 16:00-17:00 柏林电视塔观景台（备选）
→ 17:00-18:30 哈克市场＋周边街区
→ 18:30-20:00 晚餐
→ 20:00-21:00 收拾行李＋打包
```

调序规则：

- 柏林大教堂穹顶观景台需爬约270级旋转楼梯，可俯瞰博物馆岛、电视塔、施普雷河；教堂主厅有德国最大的 Sauer 管风琴（7269根音管）；地下一层是霍亨索伦王朝墓室。
- **电视塔与国会大厦穹顶都是俯瞰视角，模板已注明二选一**：昨天登过穹顶就跳过电视塔。
- 博物馆岛给3小时只够看1–2个馆，五个馆要看完得整天。
- 晚餐推荐店仅收现金，且分量很大，建议提前预订。
- 结尾的"收拾行李"是模板原客户次日早班机的产物，**客户不走时删掉**。
