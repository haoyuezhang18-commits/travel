# 慕尼黑模板索引（含新天鹅堡、国王湖）

## 城市信息

- 城市：慕尼黑
- 城市编号：MUC
- 原始模板：`德国/慕尼黑/慕尼黑三天.docx`（3张表）、`德国/新天鹅堡/德国新天鹅堡.docx`（1张表）
- 历史遗留：本模板原名 `时间段.docx`，已改为现名。如果在旧备份里看到 `时间段.docx`，指的就是这一份。
- 使用原则：慕尼黑是**中欧的枢纽 base**，本身一天就够，剩下的天数都是往外跑一日游（新天鹅堡、国王湖、萨尔茨堡）。先数客户有几天，再配几条外出线。

## 硬约束

| 项目 | 要求 |
|---|---|
| 新天鹅堡 | **门票务必提前官网购买，现场几乎买不到**；按场次入场，迟到无法进入；取票在山脚；室内全程禁止拍照 |
| 新市政厅 Glockenspiel | 每天 11:00／12:00／17:00 报时，约15分钟，提前5分钟占位 |

| 国王湖船票 | 旺季7月排队30–60分钟，**一到就先排队买票**再去洗手间 |

## 现有成熟路线

### MUC-R01 慕尼黑城内一日（夜车／清晨抵达版）

核心景点：玛利亚广场、新市政厅、圣母教堂、圣彼得教堂、谷物市场、慕尼黑王宫、英式花园。

```text
06:30-07:30 抵达慕尼黑中央火车站
→ 07:30-07:50 中央站→酒店
→ 07:50-09:00 行李寄存＋附近早餐
→ 09:00-10:00 玛利亚广场＋新市政厅
→ 10:00-10:40 圣母教堂
→ 10:40-11:40 圣彼得教堂
→ 11:40-12:40 谷物市场（Viktualienmarkt）
→ 13:00-15:00 慕尼黑王宫（Residenz）
→ 15:00-17:30 英式花园
→ 17:30-19:00 晚餐
```

调序规则：

- **Glockenspiel 报时是全天唯一的时间锚点**（11:00/12:00/17:00），先卡它再排其他。模板把 09:00–10:00 放新市政厅，其实错过了报时——调用时建议改成 10:40 前后到广场看 11:00 那场。
- 王宫古物陈列馆和庭院走廊光线最好；可现场买票，旺季建议官网提前。
- 清晨抵达版的前三行（06:30 抵达、寄存、早餐）只适用于夜车/红眼，客户正常入住时**整段删掉**，从玛利亚广场起算。

### MUC-R02 新天鹅堡（火车＋公交版）

```text
08:00-08:30 酒店早餐＋出发准备
→ 08:30-09:00 前往慕尼黑中央火车站
→ 09:00-11:00 慕尼黑→富森（Füssen）
→ 11:00-11:30 富森站→天鹅堡景区
→ 11:30-12:30 购票取票＋午餐
→ 12:30-13:30 步行上山
→ 13:30-14:30 新天鹅堡参观
→ 14:30-15:30 玛丽安桥（Marienbrücke）
→ 15:30-15:50 玛丽桥后观景台
→ 15:50-16:30 下山＋阿尔普湖
→ 16:30-17:00 返回富森火车站（公交73/78号，约15分钟）
→ 17:00-19:00 富森→慕尼黑
→ 19:00-20:30 晚餐
```

调序规则：

- 取票处在山脚，**拿到纸质票后确认参观场次，错过无法入场**。整天从门票场次倒推。
- 玛丽安桥上午9–11点、下午2–4点限流排队。这一版把参观放13:30、玛丽桥放14:30，正好撞上下午高峰——**R03 的排法更好**。
- 回程公交人多，建议提前到站台排队。

### MUC-R03 新天鹅堡（包车版，含指定场次）

```text
08:00-08:30 酒店早餐＋出发准备
→ 08:30-10:30 慕尼黑酒店→新天鹅堡景区（包车）
→ 10:30-11:00 抵达取票＋休整
→ 11:00-11:20 午餐（简餐）
→ 11:20-11:40 上山前往城堡
→ 11:40-12:00 玛丽安桥
→ 12:10-13:10 新天鹅堡参观（12:10 场次）
→ 13:40-14:00 玛丽桥后观景台
→ 14:00-14:20 下山前往阿尔卑斯湖
→ 14:20-15:20 阿尔卑斯湖（Alpsee）散步
→ 15:20-15:40 返回停车场集合
→ 15:40-17:30 新天鹅堡→慕尼黑酒店
→ 19:00-20:30 晚餐
```

调序规则：

- **这一版是刻意避峰的**：玛丽桥放 11:40（避开9–11点和14–16点两个高峰），参观放 12:10 场。调序时不要破坏这个结构。
- 山上城堡旁边有免费厕所。
- 参观全程约30–45分钟，**室内禁止拍照**，工作人员严格检查；仅在离开音乐厅时可快速拍一张，之后归还讲解器。
- 包车要**提前和司机约好具体时间和上车地点**。
- R02 和 R03 是**同一个景点的两个交通版本**，客户定了交通方式就只用一份。

### MUC-R04 国王湖一日

```text
08:00-09:00 酒店早餐＋出发准备
→ 09:00-09:30 前往中央火车站（地铁U4/U5约10分钟）
→ 09:xx 慕尼黑→贝希特斯加登（DB App 提前查好换乘站台）
→ 11:30-12:00 贝希特斯加登→国王湖码头
→ 12:00-12:30 购票＋候船
→ 12:30-13:10 游船→St. Bartholomä 教堂
→ 13:10-13:35 继续游船→Salet 码头
→ 14:15-15:30 Obersee 隐秘山湖徒步
→ 15:30-17:30 牛奶小屋＆Rothbach 瀑布（备选）
→ 16:30-17:15 返程游船 Salet→码头
→ 17:15-18:45 国王湖码头周边
→ 17:00-19:30 贝希特斯加登→慕尼黑
→ 20:00-21:30 晚餐
```

调序规则：

- **第一站 St. Bartholomä 模板明确写"没必要下船"**：红顶教堂在船上拍外部就很漂亮，内部一般，下船后排队上船的人很多，会浪费下一站徒步的时间。这条经验要保留。
- 船行进时机位：左侧岩壁倒影、右侧森林层叠；出湖湾后 St. Bartholomä 红色圆顶配雪山是明信片机位，提前准备好手机。
- Fischerei St. Bartholomä 的现熏鳟鱼是招牌，中午可能提前售罄。
- 已知问题：模板里 `15:30–17:30 牛奶小屋（备选）`、`16:30–17:15 返程游船`、`17:15–18:45 码头周边`、`16:45–17:00 返回贝希特斯加登`、`17:00–19:30 回慕尼黑` **四段互相重叠**。备选方案没被拆干净，调用时必须二选一后重排。

## 改这天要动哪几行

| 客户变量变了 | 要改的位置 |
|---|---|
| 正常入住（非夜车） | 删 R01 前三行，从玛利亚广场起算 |
| 包车 vs 火车（天鹅堡） | 只用 R02 或 R03 之一，别混 |
| 新天鹅堡场次不同 | 整天从场次倒推：参观前留30分钟排队检票，前面塞玛丽桥 |
| 天鹅堡定不到票 | 改成外观＋玛丽安桥＋阿尔普湖，明确写"未入内" |
| 加萨尔茨堡 | 见 [`cities/at/salzburg.md`](../at/salzburg.md)，同样是慕尼黑当日往返 |
| 国王湖天气不好 | 徒步段删掉，只保留游船往返，或整天换城内 |

## AI 调用规则

1. 慕尼黑是 base：城内只需 R01 一天，其余天数配 R02/R03（天鹅堡）、R04（国王湖）、萨尔茨堡。
2. 新天鹅堡的门票场次是整个订单最硬的锚点之一，框架阶段就要确认能不能买到。
3. R04 的备选段有已知重叠，必须重排。
4. 所有 DB 车次按客户日期用 DB Navigator 重查；Flixbus 富森线一天一班，错过就没有。
