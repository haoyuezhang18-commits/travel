# 塞维利亚模板索引

## 城市信息

- 城市：塞维利亚
- 城市编号：SVQ
- 原始模板：`欧洲/欧洲城市汇总版本.docx`（SVQ-R01、SVQ-R02）
- 使用原则：Day1 是马德里火车抵达的半日，Day2 是全天精华。**城市很小，主要景点靠步行，可以不买公交卡。**

## 硬约束

| 项目 | 要求 |
|---|---|
| 塞维利亚王宫（Real Alcázar） | **必须提前网上预约**，门票 €14.5；入口在教堂对面的 Plaza del Triunfo；**请按预约时间抵达** |
| 塞维利亚大教堂 | **同样需提前预约**；世界五大教堂之一；内部＋登塔约 1.5 小时 |
| 斗牛场 | 可线下直接买，约 €12；只参观建筑与博物馆，不看斗牛表演 |
| 西班牙广场 | 免费；**一定傍晚去**，有免费弗拉明戈和街头艺人 |

## 现有成熟路线

### SVQ-R01 Day1｜马德里火车抵达＋斗牛场＋都市阳伞

```text
08:00-08:45 马德里酒店退房 → 阿托查火车站
→ 09:30-12:00 火车：马德里 → 塞维利亚
→ 12:15-12:30 抵达圣胡斯塔车站 → 酒店（步行10分钟）
→ 12:30-14:30 入住／寄存行李 ＋ 午餐（安达卢西亚特色）
→ 14:30-15:00 地铁前往斗牛场
→ 15:00-16:30 塞维利亚斗牛场（Plaza de Toros de Sevilla）
→ 16:30-18:30 都市阳伞＋周边街区漫步
→ 20:15-21:45 晚餐
```

调序规则：

- **阿托查火车站出发层分两层**：planta 1（Planta Primera）才是去塞维利亚、巴塞罗那的，别走错。
- 都市阳伞往主教座堂走的那条路"倒是很好逛"（模板原话），可以顺着 Calle Sierpes 及周边小巷逛街购物。
- 晚餐 20:15 才开始——**西班牙晚餐时间晚，不要按英国习惯排 18:00**。
- 餐厅：Restaurante Doña Rufina（C. Mateos Gago, 15），推荐海鲜炖饭、炸墨鱼块。

### SVQ-R02 Day2｜王宫＋大教堂＋西班牙广场

```text
09:00-09:30 前往塞维利亚王宫（步行或公交，十几分钟）
→ 09:30-13:30 塞维利亚王宫
→ 13:30-15:00 午餐 ＋ 冰淇淋店 Gelateria MITO
→ 15:00-16:30 塞维利亚大教堂（内部＋登塔）
→ 17:00-20:00 西班牙广场游览与拍照
→ 20:30 以后 晚餐
```

调序规则：

- **王宫游览路线（模板已给，直接复用）**：佩德罗一世宫 → 哥特式宫殿 → 水渠庭院 → 地下浴场 → 花园。**整个参观约需 4 小时**，其中逛和拍照建议留 2 小时。
- **西班牙广场的五个拍照机位**（模板已标，可直接写进备注）：① 一楼拱形长廊（热门打卡地）② 彩色瓷砖墙长椅 ③ 广场中间小桥（横拍全景）④ 二楼露台（拍景拍人都宽阔）⑤ 划船（船上视角）。广场有很多马车，和马车拍照好看。
- 冰淇淋店 Gelateria MITO（C. Almirantazgo, 8），推荐芒果、柠檬、开心果、咖啡。
- 两天的晚餐都在 C. Mateos Gago 这条街（15号和18号），**同一订单要换一家**，避免重复。
