# 巴塞罗那模板索引（含 Tossa 小镇）

## 城市信息

- 城市：巴塞罗那
- 城市编号：BCN
- 原始模板：`西欧/西班牙/巴塞罗那/巴塞罗那＋Tossa 3天旅游计划.docx`（3张表）、`欧洲城市汇总版本.docx`（BCN-R04 赫罗纳）
- **⚠ 多天套装**：文件内部分了 Day1／Day2／Day3 三节，`BCN-R01` + `BCN-R02` + `BCN-R03` 是配套的三天。
- 使用原则：三张表就是三天，且主题分得很干净：Day1 高迪建筑线、Day2 老城＋海滨线、Day3 Tossa 小镇一日。天数少于3天时按主题整条删，不要每天各砍一半。

## 硬约束

| 项目 | 要求 |
|---|---|
| 交通票 | **每人必须持一张，不可共用**，查票罚 €100；坐地铁后卡背面会打印一行，剩余次数减少 |
| 圣家堂 | 建议预约 9:30 或 10:00 入场；门票含官方 APP 导览，建议自带耳机 |
| 圣家堂着装 | **严禁吊带、无袖上衣、露脐装；裙子或短裤必须过膝**，不合规会被拒绝入场 |
| 波盖利亚市场 | 周一至周六 08:00–20:30，**周日休息** |
| 巴塞罗那主教堂 | 内部禁止喧哗，同样需肩部和膝盖不外露 |

## 现有成熟路线

### BCN-R01 高迪建筑线（Day1）

核心景点：圣家堂、巴特罗之家、米拉之家、格拉西亚大道、焦糖山。

```text
09:00-09:30 交通购票
→ 09:30-12:30 圣家堂（Sagrada Família）
→ 12:30-14:00 午餐（圣家堂周边）
→ 14:00-15:30 巴特罗之家（Casa Batlló）
→ 15:30-17:00 米拉之家（Casa Milà）
→ 17:00-18:30 下午茶＋格拉西亚大道漫步
→ 18:30-19:30 焦糖山（Bunkers del Carmel）
→ 20:00-21:30 晚餐（格拉西亚区）
```

调序规则：

- 圣家堂步行/地铁 L2/L5 可达，给3小时不算多（含语音导览）。
- 巴特罗之家和米拉之家都在格拉西亚大道上，连续安排是对的。
- **焦糖山是看日落全城的机位**，18:30 这个时间要按月份调整——夏季日落21:00，冬季17:30，整条尾部跟着动。
- 模板没有奎尔公园（Park Güell），这是巴塞罗那高迪线的经典项目，客户提出时属**新增内容**，需自行查询并标记（且需提前预约时段）。

### BCN-R02 老城＋海滨线（Day2）

```text
09:30-12:00 哥特区（Barri Gòtic）Citywalk
→ 12:00-13:30 波盖利亚市场（La Boqueria）
→ 13:30-15:00 午餐（市场周边或老城）
→ 15:00-17:30 海滨漫步（Barceloneta）
→ 17:30-19:30 海边"四个盒子"日落
→ 19:30-21:00 晚餐（海滨／老城附近）
```

调序规则：

- 哥特区亲吻墙有时会有小哥主动帮拍照并打印报纸，不会主动要钱，客户自愿给一些即可——这条写进备注可以避免客户紧张。
- **海滩防骗：绝对不要理会沙滩上推销按摩、编辫子或卖"莫吉托"的小贩**（不卫生且可能被敲诈）。
- "四个盒子"（Barceloneta 海边雕塑）是日落机位，时间同样按月份调。
- 已知问题：市场在 12:00–13:30，午餐却排在 13:30–15:00，等于逛完市场再去别处吃。市场里本来就有吃的（Pinotxo 等），调用时可以合并，省出1.5小时。

### BCN-R03 Tossa 小镇一日（Day3）

```text
08:15-08:45 前往巴塞罗那北站（至少提前15–20分钟到站找站台）
→ 09:00-10:30 巴塞罗那→托萨（大巴）
→ 10:30-12:30 古城晨间摄影：狗洞＆石门
→ 12:30-14:00 古城墙漫步＋登顶
→ 14:00-15:30 午餐（高性价比精选）
→ 15:30-18:00 主海滩（Platja Gran）躺平
→ 18:00-19:00 海边餐厅日落／闲逛
→ 19:00-19:15 前往大巴站
→ 19:30-21:00 托萨→巴塞罗那
```

调序规则：

- **古城墙登顶是俯拍"果冻海"的最佳机位**，路面多石块，穿好走的鞋。
- 晨间光线是"狗洞＆石门"机位的关键，所以早班车不能改晚。
- Popa Tapes 的蜂蜜炸茄子＋气泡酒（Cava）配日落，是模板给的收尾。
- 大巴班次必须按客户日期重查，模板的 09:00 和 19:30 是某次订单的产物。

### BCN-R04 赫罗纳古城一日（当日往返，权游取景地）

原始模板：`欧洲/欧洲城市汇总版本.docx`

```text
08:00-08:30 酒店 → Barcelona-Sants 火车站（地铁约20多分钟）
→ 08:30-09:30 巴塞罗那 → 赫罗纳
→ 09:30-14:00 赫罗纳古城游览（全程步行，从火车站步行约15分钟至老城）
→ 14:00-15:00 古城内午餐
→ 15:00-15:50 返回巴塞罗那
→ 16:00-17:00 加泰罗尼亚音乐宫
→ 17:00 以后 自由活动与晚餐
```

调序规则：

- **《权力的游戏》取景地路线（模板已给，可直接复用）**：① 赫罗纳主教堂（君临城贝勒大圣堂）② 教堂右侧小路（艾莉亚学习场景）③ 圣多梅内克修道院（艾莉亚被追场景）④ Plaça dels Jurats（布拉佛斯剧院舞台，现为免费厕所）⑤ Jardins de La Francesa（艾莉亚失明乞讨处）。客户不看权游的话，这条线吸引力大减。
- 车次选择有取舍：早班车贵但玩得不赶，晚班车便宜但回来看音乐宫时间紧。**按客户预算和是否要看音乐宫决定。**
- 加泰罗尼亚音乐宫：只看外部和公共区域（大厅）可现场排队买票；**入内导览必须提前官网预约**。
- 老店推荐：Oriell 1887（百年烘焙店）、Mongourmet（芝士蛋糕专门店）。
