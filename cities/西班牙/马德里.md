# 马德里模板索引

## 城市信息

- 城市：马德里
- 城市编号：MAD
- 原始模板：`欧洲/欧洲城市汇总版本.docx`（MAD-R01、MAD-R02）
- 使用原则：两天连着用，Day1 是落地日（东侧丽池区），Day2 是老城区（西侧皇宫区）。**按城市东西两侧分天，动线不折返，这个分法要保留。**

## 硬约束

| 项目 | 要求 |
|---|---|
| 普拉多博物馆 | **必须官网提前预约**；**周末 17:00–20:00 免费**；馆内禁止拍照 |
| 马德里皇宫 | 门票 €18，官网 entradaspatrimonionacional.es；欧洲三大皇宫之一，逛 1–1.5 小时 |
| 索菲亚皇后艺术中心 | **需提前预约**；周一、周三至周六 **19:00–21:00 免费**，官网可 0 元预约，会发确认邮件 |
| 伯纳乌球场 | 参观需预订时段门票 |

**免费时段是马德里的特色**，普拉多和索菲亚都有。**排行程时优先卡免费时段**，能给客户省一大笔——但要提醒免费时段人多，要早去排队。

## 现有成熟路线

### MAD-R01 Day1｜落地＋丽池公园＋普拉多博物馆

```text
08:25 抵达马德里巴拉哈斯机场（MAD）
→ 10:00-11:00 机场巴士 203 路至市区（40分钟，€5，24小时运营）
→ 11:00-12:00 酒店 check-in／寄存行李
→ 12:00-13:30 酒店附近午餐（Retiro 区 tapas 或咖啡馆，轻食为主）
→ 13:30-15:30 丽池公园（水晶宫、划船湖、玫瑰园）
→ 15:30-16:30 阿尔卡拉门＋西贝莱斯广场
→ 16:30-18:30 普拉多博物馆（重点看戈雅、委拉斯贵支）
→ 18:30-19:30 太阳门附近晚餐
→ 19:30 以后 酒店休息或夜景散步
```

调序规则：

- 机场有 4 个航站楼，航站楼之间有免费巴士；**最方便是机场巴士 203 路**，€5、40分钟、24小时不打烊。
- 交通票在机场就买好 **10 次票**，两天够用。
- 落地第一天别吃太饱、别排太满，模板刻意把强度压得很低。
- **普拉多如果落在周末，把时段挪到 17:00–20:00 走免费场**，前面的丽池公园可以延长。

### MAD-R02 Day2｜皇宫＋太阳门＋圣米格尔市场＋伯纳乌

```text
09:00-09:30 酒店 → 皇家宫殿区（地铁约30分钟）
→ 09:30-11:30 马德里皇宫（外部＋内部）
→ 11:30-12:00 主教座堂（Catedral de la Almudena）
→ 12:00-12:30 步行至太阳门广场（约800m，顺路下坡）
→ 12:30-13:30 太阳门广场＋周边逛街＋午餐
→ 13:30-14:00 主广场（Plaza Mayor）
→ 14:00-14:45 圣米格尔市场（重头戏）
→ 14:45-16:15 伯纳乌球场
→ 16:45-18:15 索菲亚皇后艺术中心
→ 18:30 以后 晚餐
```

调序规则：

- **皇宫推荐动线（不走回头路，模板已验证）**：入口 Santiago 门 → 主阶梯（穹顶壁画）→ 王座厅 → 加斯帕里尼厅（洛可可繁饰极致）→ 国宴厅 → 出口 → Sabatini 花园休息 → 可接德波神庙。
- **早点到皇宫避开排队高峰。**
- 主教座堂免费进，内部是现代风格；登顶可俯瞰王宫全景（额外 €6，可选）。
- 圣米格尔市场是模板标的"重头戏"：火腿、海鲜、paella、甜点、葡萄酒，预算 €20–30/人。
- 索菲亚卡在 19:00 免费场的话，晚餐要推到 21:00 后（西班牙晚餐本来就晚）。
