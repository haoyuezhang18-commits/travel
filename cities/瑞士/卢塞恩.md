# 卢塞恩模板索引

## 城市信息

- 城市：卢塞恩（琉森）
- 城市编号：LUC
- 原始模板：`瑞士/卢塞恩/卢塞恩2天通用.docx`（4张表）
- 使用原则：4张表实际是"抵达半日＋老城全日＋瑞吉山全日＋瑞吉山转场日"。卢塞恩老城很小，全部景点步行可达，真正吃时间的是瑞吉山。先决定去不去瑞吉山。

## 硬约束

| 项目 | 要求 |
|---|---|
| 瑞吉山船＋齿轨 | 有 Swiss Pass 船票免费；无通票在 SBB App 提前买 Rigi Day Pass 套票 |
| 穆塞格城墙 | 免费，夏季约8:00–19:00；只登 Männli 塔（风景最好）和 Zyt 塔（整点报时钟） |
| 山顶气温 | 瑞吉山1797米，10月约5–10℃，即使夏天也要防风外套 |
| 瑞士超市 | 周日全关，平日约18:30关门 |

## 现有成熟路线

### LUC-R01 米兰抵达半日

核心景点：卡佩尔桥＆水塔、琉森湖游船（可选）、垂死狮子纪念碑、老城购物、湖边晚餐。

```text
09:40-10:10 前往米兰中央站
→ 10:10-13:41 米兰→卢塞恩（约3.5h）
→ 13:41-14:00 抵达→存行李
→ 14:00-15:00 老城区午餐
→ 15:00-15:45 卡佩尔桥＆水塔
→ 15:45-17:15【可选替代】琉森湖游船
→ 17:15-17:45 垂死狮子纪念碑
→ 17:45-18:30 老城漫步＆购物
→ 18:30-18:45 办理酒店入住
→ 18:45-20:00 湖边晚餐
→ 湖边夜景散步（喂天鹅、天鹅广场名表珠宝店）
```

调序规则：

- 出站就能看到琉森湖和雪山，模板建议出站先拍一张。
- 前台要一张免费地图标记当天景点。
- **游船和穆塞格城墙是同一时段的两个选项**（各约1–1.5小时），二选一。想两个都要就换 R02 的全日版。
- 有半价卡时公交在 App 搜 `Lucerne Train Station → Casino-Palace`，页面直接展示半价单程票。
- 建议提前在 Trenitalia 或 SBB 官网购米兰段车票，二等舱约€30–50/人。

### LUC-R02 老城全日版

```text
09:00 耶稣会教堂＆巧克力
→ 10:00-11:30 老城区＆穆塞格城墙（登 Männliturm）
→ 11:30-13:30 老城午餐（4选1）
→ 13:30-15:30 冰川公园＆狮子像
→ 15:30-17:00 圣莱奥德伽尔教堂
→ 17:00-19:00 卡佩尔廊桥＆购物
→ 19:00-20:30 湖景／意式晚餐
→ 码头休闲时光
```

调序规则：

- 城墙楼梯很窄，登顶可俯瞰整座琉森城；5月湖边风大、城墙上更高，建议防风外套。
- 购物：Moncler 等如有购买计划要赶在专柜关门前，退税起征点通常 CHF 300。

### LUC-R03 瑞吉山全日版（当天返回卢塞恩）

```text
09:00-09:12 酒店→码头
→ 09:12-10:09 船：卢塞恩码头→维茨瑙（Vitznau）
→ 10:15-10:47 齿轨火车：维茨瑙→瑞吉山顶（Rigi Kulm）
→ 10:47-12:00 山顶360°观景
→ 13:00-14:30 瑞吉山景观午餐
→ 14:30-15:30 轻徒步
→ 15:30-15:40 缆车：Rigi Kaltbad→Weggis
→ 15:40-15:50 船：Weggis→卢塞恩码头
→ 卢塞恩晚餐
```

调序规则：

- **上下山齿轨都要坐左侧**，才能拍到湖景与雪山同框。
- Rigi Kaltbad 下来的缆车基本是站票，站着俯瞰湖景。
- 山顶风大得离谱，即使夏天也要带薄外套。
- 这一版走的是"船上山、缆车下山"的环线，不走回头路，**顺序不要倒过来**。

### LUC-R04 瑞吉山＋转场因特拉肯版

```text
07:30-08:00 酒店早餐＋退房
→ 08:00-08:30 步行至卢塞恩码头
→ 08:30-09:25 船：卢塞恩→维茨瑙
→ 09:25-10:00 齿轨：维茨瑙→瑞吉山顶
→ 10:00-11:30 瑞吉库尔姆峰顶（1797m）
→ 11:30-12:05 峰顶→维茨瑙
→ 12:05-13:00 维茨瑙→卢塞恩
→ 13:00-13:45 取行李＋快速午餐
→ 14:02-15:52 卢塞恩→因特拉肯（黄金列车，**坐右侧**看布里恩茨湖）
→ 15:52-16:30 抵达因特拉肯东站→入住
→ 因特拉肯小镇漫步＋晚餐＋湖边夜景
```

调序规则：

- 比 R03 早出发1小时，因为下午要赶黄金列车。**旺季首班船可能要提前到码头**，出发前在 SBB App 确认首班时刻。
- 10月山顶可能有薄雾或低云，出发前查 Swiss Meteo，**能见度3级以上才值得上山**；云海在脚下反而更梦幻。
- 下山时车身倾斜更明显，扶好。
- 这一版的后半段其实是因特拉肯的内容，详见 [`cities/瑞士/伯尔尼高地.md`](伯尔尼高地.md)。

## AI 调用规则

1. 先决定**去不去瑞吉山**：去就是 R03／R04（整天），不去就是 R01＋R02。
2. 瑞吉山必须写天气替代方案（改 R02 老城版），瑞士山区行程不写替代方案等于没做。
3. 船班、齿轨、缆车时刻必须按客户日期在 SBB App 重查，模板时刻只是参考。
4. 坐哪一侧的提示（齿轨左侧、黄金列车右侧）是模板的加分内容，保留写进客户备注。
