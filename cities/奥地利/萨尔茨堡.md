## 现有成熟路线

### SZG-R01 慕尼黑当日往返

核心景点：米拉贝尔花园、莫扎特故居（外观）、莫扎特出生地（外观）、主教宫、霍亨萨尔茨堡要塞。

```text
08:00-08:30 前往慕尼黑中央火车站
→ 08:30-09:00 火车站候车
→ 09:00-10:50 慕尼黑→萨尔茨堡
→ 10:50-11:15 抵达＋购买萨尔茨堡卡＋洗手间
→ 11:30-12:30 米拉贝尔花园
→ 12:30-12:45 莫扎特故居（外观）
→ 12:45-13:00 过河＋莫扎特出生地（外观）
→ 13:00-13:15 买莫扎特巧克力球
→ 13:15-14:15 午餐
→ 14:30-16:30 萨尔茨堡主教宫（Residenz）
→ 16:40-18:00 霍亨萨尔茨堡要塞（缆车）
→ 18:30-19:00 下山＋老城自由活动
→ 19:00-19:30 返回火车站
→ 19:30-21:20 萨尔茨堡→慕尼黑
```

调序规则：

- **主教宫 14:00 前必须进入**（16:30清场），这决定了午餐必须在13:15–14:15、上午所有景点都是快节奏打卡。这个结构是对的，不要为了多逛米拉贝尔花园而推迟。
- 主教宫有免费中文讲解器（或扫码听讲解）和免费寄存处（食水不能带入）。
- 莫扎特故居和出生地这一版**只安排外观**（各15分钟）。客户是古典乐爱好者时要入内，各需1小时，那就得砍掉主教宫或要塞。
- 模板注明 **Alter Markt 的莫扎特巧克力球老店目前装修关闭，不用去找**——这条信息会过期，制作时复查。
- 午餐推荐 Zwettler's Wirtshaus（Kaigasse 3，人均€20–30，红酒烩牛尾€25.80、芝士面疙瘩 Kasnockn €13.9，点小份就够）。

## 模板缺什么

- **《音乐之声》取景地线**（米拉贝尔花园的 Do-Re-Mi 台阶已含，但海尔布伦宫玻璃亭、侬山修道院、월湖等都没有）。客户冲着《音乐之声》来时，属新增内容。
- 盐矿、鹰巢（Kehlsteinhaus）、哈尔施塔特——这三个是萨尔茨堡周边最常被点名的一日游，模板全无。
