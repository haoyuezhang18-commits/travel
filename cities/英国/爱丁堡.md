# 爱丁堡模板索引（含格拉斯哥一日）

## 城市信息

- 城市：爱丁堡（含从爱丁堡出发的格拉斯哥一日）
- 城市编号：EDI
- 原始模板：`城市/爱丁堡/爱丁堡两天通用版本.docx`（5张表，28图）、`城市/格拉斯哥 /格拉斯哥.docx`（1张表）
- 使用原则：5张表覆盖"火车抵达半日／经典全天／精简一日／夜巴抵达／荷里路德宫＋Dean Village"。**先确定抵达方式和停留天数**，再选表。

## 硬约束

| 项目 | 要求 |
|---|---|
| 爱丁堡城堡 | **必须提前官网订票并选好入场时段**，现场买票很可能排很久甚至没票 |
| 荷里路德宫 | **必须提前官网买票**，成人£22／青年£14／儿童£11，含中文语音导览 |
| 苏格兰国家画廊 | 免费 |
| 苏格兰国立博物馆 | 永久展厅免费（特展收费），**不需要预约，直接进** |
| 爱丁堡大学老学院 | 内部有时因活动关闭，庭院和外观全天开放、免费 |
| 卡尔顿山日落 | **按月份重算**：7月底约21:00–21:30，建议20:00左右上山占位 |

城堡建在死火山岩顶上，全程缓坡上行；爱丁堡多坡道——**带老人或行动不便的客户要提前说明**。

## 现有成熟路线

### EDI-R01 伦敦火车抵达日（半日）

```text
07:30-08:30 酒店退房 → 国王十字站
→ 08:30-09:30 国王十字站超市采购
→ 09:30-13:38 跨城高铁：伦敦 → 爱丁堡（LNER）
→ 13:38-14:30 抵达 Waverley 站 → 酒店入住
→ 14:30-16:30 苏格兰国家画廊（免费）
→ 16:30-17:00 王子街花园 → 司各特纪念碑
→ 17:00-18:00 购物
→ 18:00-19:30 晚餐
→ 19:30-21:15 卡尔顿山看日落
```

调序规则：

- **火车务必选右侧靠窗**：过了约克之后窗外会出现北海海岸线。这条写进客户备注是加分项。
- 晚餐：Makars Mash Bar（需提前预约，点一份 Haggis 哈吉斯）；Howies（苏格兰菜，搭配土豆泥）。**必喝橘色包装的 Irn-Bru 汽水**（苏格兰"神水"）。
- 卡尔顿山日落时间随月份变化极大（夏季21:30、冬季16:00），必须重算。

调序规则：

- 城堡必看（模板已给，可直接写进备注）：苏格兰皇冠珠宝、命运之石、圣玛格丽特教堂（爱丁堡现存最古老建筑）、战争纪念馆。
- 大象咖啡馆非常火，可能要排队；午餐那家也火爆，建议提前预约。
- 晚餐选在卡尔顿山脚下是刻意的——吃完直接上山看日落，不折返。**调序时保留这个衔接。**
- 圣吉尔斯大教堂周日上午礼拜，普通参观通常下午开始。

### EDI-R06 格拉斯哥一日（爱丁堡出发）

原始模板：`城市/格拉斯哥 /格拉斯哥.docx`

```text
08:30-09:30 爱丁堡 → 格拉斯哥
→ 09:30-10:00 乔治广场 & 现代艺术美术馆（GoMA）
→ 10:20-12:00 格拉斯哥大教堂与大墓地
→ 12:00-13:30 午餐
→ 13:30-14:00 前往西区
→ 14:00-15:30 格拉斯哥大学
→ 15:30-17:00 凯文葛罗夫艺术博物馆
→ 17:00-17:30 返回市中心
→ 17:30-19:30 布坎南街购物与晚餐
```

调序规则：

- GoMA 门前**头戴"雪糕筒"的惠灵顿公爵骑士雕像**是格拉斯哥的标志机位，无需门票和预约。
- 大教堂与大墓地紧邻，都免门票免预约；大教堂地下地层（Lower Church）注意看彩窗；大墓地无遮挡，阴雨天地面湿滑。
- **格拉斯哥坐公交必须提前向司机抬手招手示意，否则车辆直接驶过不停靠。** 这条一定要写进客户文件。
- **格拉斯哥地铁是环线，分内环（Inner）和外环（Outer）**，购票进站要看行驶方向。
- 年龄提醒：**14岁在英国公共交通中属青年/成人**，无法买儿童免票，大巴或火车都要买足额青年票或全票。
- 8月1日格拉斯哥日落约21:14，傍晚17:30后天色仍明亮。
