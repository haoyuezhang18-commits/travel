## 现有成熟路线

### LON-R01-A 西敏经典线｜换岗日上午版

适用：确认当天有白金汉宫换岗时使用。

```text
10:00 酒店出发
→ 11:00-12:00 白金汉宫（换岗）
→ 12:00-13:30 午餐
→ 13:30-14:30 圣詹姆斯公园
→ 14:30-15:00 唐宁街10号、白厅大街
→ 15:30-17:00 威斯敏斯特教堂
→ 17:00-18:00 伦敦眼 & 大本钟
→ 18:00-18:30 下午茶／点心
→ 18:30-19:00 购物伴手礼小店
→ 19:00-19:30 伦敦塔桥 + 伦敦塔
→ 19:30-20:00 晚餐
```

调序规则：

- **换岗与否决定上下午顺序**，这是伦敦最核心的一条调序规则。有换岗才用这一版。
- 结尾的塔桥＋伦敦塔只给30分钟，是"路过外观"的量。客户要进伦敦塔必须另开半天（需2–3小时）。

### LON-R01-B 西敏经典线｜无换岗／西敏优先版

适用：没有换岗，或需要优先进入威斯敏斯特教堂时。

```text
09:30-10:00 前往国家美术馆
→ 10:00-12:30 国家美术馆
→ 12:30-13:00 特拉法加广场
→ 13:00-14:00 午餐
→ 14:20-15:45 威斯敏斯特教堂
→ 15:45-16:30 大本钟 + 议会广场 + 威斯敏斯特桥
→ 16:30-18:00 下午茶／购物伴手礼小店
→ 18:00-19:30 晚餐
→ 19:30-20:00 等候 + 换票
→ 20:30-21:00 伦敦眼（黄金时段过渡到日落）
```

调序规则：

- 国家美术馆免费、无需预约，入口可领免费中文地图。
- 伦敦眼放在20:30是刻意的：夏季日落约21:07，这个时段从黄金时段过渡到日落，视觉最好。**日落时间随月份变，这个时段必须重算。**
- 没有换岗时白金汉宫仍可安排外观拍照，但优先放下午。

### LON-R03-B 伦敦南岸文艺线｜海德公园衔接版

适用：外地抵达伦敦后衔接南岸，按抵达时间删减。

```text
抵达伦敦（模板为银石→帕丁顿 09:17-09:56）
→ 10:30-11:30 海德公园
→ 13:00-14:30 博罗市场
→ 14:30-16:30 泰特现代美术馆 或 V&A博物馆
→ 16:30-18:00 泰晤士河南岸慢步
→ 18:00-19:30 南岸晚餐（Padella）
→ 19:30-20:00 千禧桥夜景
```

调序规则：

- 泰特现代和 V&A **二选一**，两个馆分处南北岸，都去会来回折返。
- V&A 镇馆之宝清单（模板已给，可直接写进备注）：达芬奇手稿（1楼64展厅）、女王皇冠（2楼91展厅）、拉斐尔挂毯图稿（0层48A）、图拉真柱（0层46）、帝普老虎（0层41）、阿达比勒地毯（0层42）。
- 开头的"银石→帕丁顿"是原客户的自驾行程，**换客户必须整段替换**。

## AI 调用规则

1. **先查换岗**：决定用 R01-A 还是 R01-B。这是伦敦订单最常见的第一个判断。
2. 客户需要的景点在上述清单中：打开对应原始表格直接复用详细内容，再改客户变量。
3. 同一景点在多条路线中重复（大英博物馆出现4次、圣保罗3次、碎片大厦3次）：**只选与客户天数最接近的一条**，不要跨表拼接。
4. 景点不在清单中：自行查询并新写，明确标记"新增内容"。
5. 涉及交通衔接（住哪→去哪个站、机场往返）时，**先查交通话术库**，里面有按住宿区域写好的现成话术，不要自己重编。
6. 涉及餐厅时先查餐厅推荐库，按区域取1–2家，不要整段复制。
7. 广场、街道、拍照点、餐厅和商店通常保留在路线中，不单独建立景点资料卡。
8. 新写内容经人工确认后，只需把景点名字加入本页清单。
