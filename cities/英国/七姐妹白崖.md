# 七姐妹白崖模板索引（含布莱顿、坎特伯雷串联）

## 区域信息

- 区域：东萨塞克斯海岸（七姐妹白崖、布莱顿、伊斯特本）
- 区域编号：SSC（Seven Sisters Cliffs）
- 原始模板：
  - `城市/白崖/白崖一天往返通用版本.docx`（2张表：火车往返版、牛津自驾版）
  - `城市/白崖/布莱顿＋白崖.docx`（1张表）
  - `城市/白崖/坎特伯雷＋白崖.docx`（1张表）
- 合并成一页的原因：四个版本的**白崖徒步段完全相同**，区别只在前半天加了什么（纯白崖／布莱顿／坎特伯雷）和怎么来（火车／自驾）。分开读会把同一段徒步说明读四遍。

## 所有版本共用的两条铁律

> **天气是关键：一定要挑个大晴天去。** 阴天或下雨，白崖会失去大部分魅力，泥泞的山路也很难走。
>
> **注意安全：白崖地貌脆弱，风也很大，拍照时请远离悬崖边缘，不要蹦跳。**

这两条模板里反复出现，**必须原样写进客户文件**。同时意味着：白崖行程一定要给客户一个"天气不好怎么办"的替代方案（通常改布莱顿市内或伊斯特本海滨）。

## 徒步段（四个版本共用）

白崖精华段从东往西：**Beachy Head（红色灯塔）→ Belle Tout Lighthouse（白色灯塔）→ Birling Gap → Coastguard Cottages（《赎罪》白房子）**

- Beachy Head → Belle Tout 约25–30分钟，是拍红白条纹灯塔的最佳机位，也是七姐妹白崖最高点。
- Birling Gap 有游客中心和餐厅，可以下海滩。
- 徒步强度不低，**不要把多段徒步写得过轻松**；风力、天气和日落时间都要考虑。
- 从 Birling Gap 走回 Beachy Head 约30–35分钟；在 Beachy Head 可打车回 Eastbourne 站（约£10–15），建议提前用 Uber 预约或让游客中心帮忙叫车。

## 现有成熟路线

### SSC-R01 纯白崖火车往返（从伦敦）

```text
09:00-09:30 前往 Victoria 站
→ 09:46-11:15 伦敦Victoria → Eastbourne
→ 11:15-11:30 火车站 → Beachy Head
→ 11:30-12:30 午餐（The Beachy Head Pub，4.1分／£20-25，周日烘烤和炸鱼薯条）
→ 12:30-14:30 精华徒步：Beachy Head 灯塔 → Birling Gap
→ 14:30-15:00 Birling Gap 下海 & 休息
→ 15:00-16:00 赎罪白房子
→ 16:30-17:30 East Dean → Eastbourne 火车站
→ 17:30-18:30 晚餐
→ 18:30-19:30 Eastbourne → Victoria 站
```

调序规则：这一版**先吃饭再徒步**，把午餐当"起点能量站"，适合体力一般的客户。

### SSC-R02 牛津自驾版（白崖 → 伦敦还车）

```text
09:00 牛津酒店退房
→ 09:00-11:15 牛津 → South Hill Barn Car Park
→ 11:15-12:15 第一站打卡（白房子全景）
→ 12:15-12:35 → Birling Gap
→ 12:35-13:35 午餐（Birling Gap 游客中心餐厅）
→ 13:35-15:00 下海滩 + 徒步 Belle Tout 灯塔
→ 15:00-15:45 比奇角 Beachy Head
→ 15:45-16:45 晚餐（Bistrot Pierre，火车站旁小镇，4.1分／£20-30，无敌海景，非常火爆必须提前预订）
→ 16:45-18:45 白崖 → 伦敦市区还车点
→ 18:15 伦敦酒店入住
```

调序规则：

- **South Hill Barn Car Park 免费停车（限时12小时）**，这是自驾版的关键信息。
- 白房子全景机位早中期光线最好，所以自驾版把它放在第一站。
- 返程一路向北开，**注意防范落日夕阳刺眼**。
- 还车：满油还车，保留最后一次加油小票。
- 已知问题：`16:45–18:45 回伦敦` 与 `17:45–18:15 还车办理` 时间重叠，调用时重排。

### SSC-R03 布莱顿 + 白崖（火车＋公交）

```text
09:00-09:30 前往 Victoria 站
→ 09:30-10:30 London Victoria → Brighton
→ 10:40-11:15 Brighton站 → 英皇阁
→ 11:15-12:00 英皇阁（Royal Pavilion）
→ 12:10-12:50 布莱顿码头 + 午餐
→ 12:50-13:30 坐 12X/13X 公交前往七姐妹白崖
→ 13:30-14:30 Coastguard Cottages（《赎罪》白房子）
→ 14:30-15:20 徒步 → Birling Gap
→ 15:20-15:50 Birling Gap 下海 & 休息
→ 15:50-16:30 徒步 → Belle Tout Lighthouse
→ 16:30-17:10 徒步 → Beachy Head
→ 17:10-17:40 Beachy Head → Eastbourne 站
→ 17:40-18:40 晚餐（Eastbourne）
→ 18:46-20:11 Eastbourne → Victoria 站
```

调序规则：

- 这一版徒步方向**从西往东**（白房子→Birling Gap→Belle Tout→Beachy Head），与 R01/R02 相反，因为公交把人放在西端。**不要和其他版本混用方向。**
- 布莱顿码头的食物适合在海边拿着吃，但**要注意防备海鸥**。
- 全天强度最高（上午逛城＋下午徒步4小时），带老人小孩要砍掉英皇阁或缩短徒步。

### SSC-R04 坎特伯雷 + 白崖（火车串联）

```text
08:00-08:30 酒店 → St Pancras International
→ 09:40-10:34 St Pancras → Canterbury West
→ 10:45-11:15 西门花园（Westgate Gardens）
→ 11:15-11:50 坎特伯雷撑篙游船（Punting）
→ 11:50-12:00 午餐（外带，火车上吃）
→ 12:00-12:20 大教堂 + 书店 + 歪房子（外观打卡）
→ 12:23-14:45 Canterbury West → Eastbourne
→ 15:10-18:00 七姐妹白崖精华徒步
→ 18:00-18:35 返回 Eastbourne 火车站
→ 18:35-19:15 晚餐
→ 19:20-21:03 Eastbourne → London Victoria
```

调序规则：

- 撑篙游船信息：Westgate Punts（西门花园旁，步行2分钟），每日10:00–17:00，约45分钟，约£30/船（坐2–4人），沿斯陶尔河。
- 坎特伯雷大教堂周日11:30–17:00（最后入场16:00），成人约£15–17；必看三位一体礼拜堂（托马斯·贝克特殉道之地）、哥特式回廊、地下室。**如果入内，12:50前必须出来。**
- 周日地铁班次较少，去 St Pancras 要提前查。

**已知问题（这一版时间轴有四处硬伤，必须重算）：**

1. 候车段 08:30–08:40 结束，但列车 09:40 才出发，中间1小时未解释。
2. 撑篙 11:50 结束后，只给大教堂＋书店＋歪房子 **20分钟**（12:00–12:20），而模板自己又写"如果入内12:50前必须出来"——自相矛盾。
3. 从大教堂区域到 Canterbury West 站只预留 **3分钟**（12:20–12:23），不现实。
4. 午餐被压缩成"11:50–12:00 外带10分钟"。

**调用原则：保留"坎特伯雷在前、白崖在后"的城市顺序，但整天时间轴必须重做。** 现实的做法是：要么放弃大教堂入内只拍外观，要么放弃撑篙，二选一。
