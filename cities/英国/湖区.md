# 湖区模板索引（温德米尔／鲍内斯／安博塞德／格拉斯米尔）

## 区域信息

- 区域：英格兰湖区（Lake District）
- 区域编号：LAK
- 原始模板：`城市/温德米尔/湖区通用5版本.docx`（5张表，17图）
- 历史遗留：本模板原名 `温德米尔自驾一日游模板.docx`，但实际含 5 个版本（含火车版、两天版、游船＋蒸汽火车版），已改为现名。旧备份里看到"温德米尔自驾一日游模板"指的就是这一份。
- 使用原则：先确定**自驾还是火车**、**住不住湖区**，再选版本。

## 硬约束

| 项目 | 要求 |
|---|---|
| 温德米尔湖游船 | 首班 9:50 / 末班 17:55，**末班标 one way only 是单程不返回，别坐错** |
| 游船＋蒸汽火车联票 | windermere-lakecruises.co.uk 可提前线上购票；**联票不预留座位**，旺季建议提前排队登船；全程环线约3.5小时 |
| Lakeside 换乘 | **下船到蒸汽火车站台衔接仅10分钟，切勿停留拍照，错过要等1小时** |
| 彼得兔博物馆 | 现场排队久，建议官网提前买票；门票不便宜，**可直接去它极大的纪念品商店买正版周边** |
| 自驾停车 | 提前下载 **Paybyphone** App；White Moss 停车场厕所永久关闭，要在安博塞德先解决 |
| Rydal Cave 徒步 | 必须穿防滑运动鞋，是行程里最耗体力的点 |

## 现有成熟路线

### LAK-R01 自驾综合版（爱丁堡来，当晚住湖区）

```text
08:30-11:00 爱丁堡自驾前往湖区
→ 11:00-12:15 格拉斯米尔（Grasmere）
→ 12:30-13:40 安博塞德（Ambleside）午餐
→ 13:40-14:50 精华徒步：Rydal Cave 探险（往返约1.5小时）
→ 15:00-16:15 鲍内斯码头（Bowness）游船
→ 16:15-17:15 彼得兔博物馆与小镇闲逛
→ 17:15-18:00 前往酒店办理入住
→ 19:30 以后 晚餐
```

调序规则：

- **省钱 Tips：如果住温德米尔 High Street 附近，晚上18:00后很多路边车位可以免费不限时停放。**
- 晚餐需提前官网预约；Francine's（海鲜与传统英式）**仅晚18:00营业**，需提前预约。
- 这一版一天塞了小镇＋徒步＋游船，节奏偏紧，带老人小孩要砍掉 Rydal Cave。

### LAK-R02 抵达休闲版（两天中的第一天）

```text
09:30-12:00 爱丁堡出发 → 温德米尔
→ 12:00-13:00 温德米尔站 → 酒店
→ 13:00-14:00 办理入住 + 码头午餐
→ 14:00-15:00 温德米尔湖游船
→ 15:00-16:00 彼得兔博物馆
→ 16:00-17:30 小镇漫步／户外用品／喂天鹅
→ 17:30-19:00 晚餐
```

调序规则：节奏最松，适合抵达当天。孩子对彼得兔有执念时，码头步行5分钟就是 The World of Beatrix Potter，建议官网提前买票。

### LAK-R03 小镇版（两天中的第二天）

```text
09:30-10:00 温德米尔 → 安博塞德
→ 10:00-11:00 安博塞德打卡
→ 11:00-12:00 午餐
→ 12:30-13:00 安博塞德 → 格拉斯米尔
→ 13:00-14:00 格拉斯米尔姜饼屋
→ 14:00-15:30 华兹华斯故居（Dove Cottage）
→ 15:30-17:00 返程温德米尔
```

调序规则：全程小镇＋室内，**这是天气不好时的标准替代方案**。

### LAK-R04 徒步版（两天中的第二天，体力好）

```text
09:30-10:00 温德米尔 → 安博塞德
→ 10:00-10:45 安博塞德打卡
→ 10:45-11:00 安博塞德 → White Moss 停车场
→ 11:00-13:00 Rydal Cave 环形徒步（精华项目）
→ 13:00-13:30 → 格拉斯米尔
→ 13:00-14:00 午餐（格拉斯米尔）
→ 14:00-15:00 格拉斯米尔姜饼屋
→ 15:00-16:30 华兹华斯故居（Dove Cottage）
→ 16:30-17:00 返程温德米尔
```

调序规则：

- Rydal Cave 环线：全程5.1公里，1.5–2小时，海拔爬升197米，**难度"轻松"、大部分是维护良好的平坦步道，适合各年龄段**，建议顺时针走。
- White Moss 停车场（邮编 LA22 9SE）：南北两区共140个车位，**厕所永久关闭**，要在安博塞德先上；停车费用 Paybyphone。
- 格拉斯米尔停车：Stock Lane Car Park 是镇里较大的公共停车场（Pay & Display），也有路边免费位（注意看清标志）。
- 已知问题：`13:00–13:30 去格拉斯米尔` 与 `13:00–14:00 午餐` 时间重叠，调用时重排。

### LAK-R05 游船＋蒸汽火车版（曼彻斯特来，火车）

```text
08:30-09:00 前往曼彻斯特火车站
→ 09:00-11:00 曼彻斯特 → 温德米尔站
→ 11:00-11:30 抵达 → 前往 Bowness 酒店放行李
→ 11:30-12:30 Bowness 小镇 & 午餐
→ 13:00-13:40 Bowness 码头乘船 → Lakeside 码头
→ 13:40-13:50 码头换乘（仅10分钟，不要停留拍照）
→ 13:50-14:10 Lakeside → Haverthwaite 蒸汽小火车（约18分钟）
→ 14:10-14:40 Haverthwaite 站内自由游览
→ 14:40-15:00 返回 Lakeside
→ 15:00-15:40 Lakeside 乘船返回 Bowness（黄线游船约40分钟）
→ 15:40-17:00 彼得兔博物馆
→ 17:00-18:00 Bowness 小镇闲逛
→ 18:00-19:30 Bowness 晚餐
```

调序规则：

- 蒸汽火车段**优先选右侧窗边**，河谷＋蒸汽烟雾同框是绝佳机位。
- 回程游船坐右侧适合拍湖景；湖面日晒较强，带防晒。
- 晚餐：Homeground（4.4，£20–30，湖景，亲子友好）／The Crafty Baa（4.2，£15–25，炸鱼薯条分量足）／Lucia's（4.3，£20–28，披萨意面，适合儿童，建议订位）。
- 已知问题（模板自己的旧毛病）：**模板把"曼彻斯特站→温德米尔站"和"火车上"拆成 09:00–09:30 和 09:30–11:00 两行，实际属于同一段跨城交通。** 调用时按真实班次合并成一行。
