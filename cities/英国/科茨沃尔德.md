# 科茨沃尔德模板索引

## 区域信息

- 区域：科茨沃尔德（Cotswolds）
- 区域编号：COT
- 原始模板：`城市/科茨沃尔德/科茨沃尔德两天.docx`（2张表）
- 使用原则：两天路线，**base 是 Bourton-on-the-Water**（两晚都住这里）。客户住别处时，两天的首尾都要重排。

## 硬约束

| 项目 | 要求 |
|---|---|
| 801 路公交（牛津→Bourton方向） | **班次很少，务必提前查好时刻表** |
| 855 路公交（Bourton→Bibury） | **班次极少，错过一班可能要等1–2小时** |
| Bibury → Castle Combe | **这一段必须包车**，没有可行的公共交通 |
| The Manor House 下午茶 | 建议提前预约 |

**模板混合了"包车／公共交通"两种写法。** 客户确定交通方式后，必须统一，不能一半包车一半公交。

## 现有成熟路线

### COT-R01 第一天：抵达 Bourton-on-the-Water

```text
09:00-09:30 牛津酒店退房 → 出发
→ 09:30-10:30 途中（约1-1.5小时）
→ 10:30-11:00 抵达 Bourton 酒店 → 放行李
→ 11:00-12:30 Bourton-on-the-Water
→ 12:30-13:30 午餐
→ 13:30-15:00 Bourton②：模型村 & 其他景点
→ 15:00-17:00 自由活动 / 休息
→ 17:00-18:30 晚餐
```

调序规则：

- 交通两方案：**A 包车（推荐）**，到酒店接、行李放车上直接出发；**B 公共交通**，801路班次很少必须提前查。
- 模型村周边景点都在游客中心步行10分钟内，但**不建议都去，选1–2个即可，否则老人孩子太累**。
- 酒店推荐（模板已给）：Chester House Hotel（前台友善，有老人要求不爬楼梯很爽快答应）／The Old New Inn（村中心，有花园餐厅酒吧）／The Plough B&B（免费WiFi和酒吧）。**建议预订时备注同行人构成。**
- 9月中旬日落约19:15，吃完饭可以在河边看日落。

### COT-R02 第二天：Bibury + Castle Combe

```text
08:30-09:00 酒店早餐
→ 09:00-09:45 Bourton → Bibury（855路，班次极少）
→ 09:45-12:00 Bibury（拜伯里）游览
→ 12:00-13:00 午餐
→ 13:00-13:45 Bibury → Castle Combe（必须包车）
→ 13:45-16:30 Castle Combe（库姆堡）游览
→ 16:30-17:30 下午茶／点心
→ 17:30-18:30 Castle Combe → Bourton 酒店
→ 18:30-19:30 晚餐
```

调序规则：

- **Bibury 很小，半小时到一小时就能逛完主要景点**——模板给了2小时15分钟，是"慢节奏"的排法。赶时间的客户可以压缩到1小时，把时间给 Castle Combe。
- 午餐：花园餐厅对着田园风光，推荐烤鱼薯条和**周日限定的 Sunday Roast Beef**（烤牛肉配约克布丁）——落在周日是加分项。
- 下午茶：The Manor House Hotel 的经典英式下午茶（百年庄园、司康配凝脂奶油、庭院座位），建议提前预约。
