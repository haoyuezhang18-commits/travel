# 伦敦当日往返模板索引（温莎／剑桥／牛津／南安普顿／哈利波特影城）

## 区域信息

- 区域：以伦敦为 base 的当日往返一日游
- 区域编号：LDT（London Day Trip）
- 原始模板：
  - `城市/温莎城堡/温莎城堡通用版本.docx`（1张表）
  - `城市/剑桥/剑桥往返通用版本.docx`（2张表）
  - `城市/牛津/牛津往返通用.docx`（2张表）
  - `城市/南安普顿/南安普顿一日游.docx`（1张表）
  - `城市/哈利波特影城/哈利波特影城通用版本.docx`（1张表）
- 合并成一页的原因：五条线全部是**早上从伦敦出发、当晚回伦敦**，共用同一套火车票逻辑（Off-Peak Day Return + Railcard）和同一个"住哪→去哪个站"的问题。分开读五份模板会把同样的购票说明重复五遍。

## 五条线共用的火车票规则

- **往返一律买 Off-Peak Day Return（Open Return）**，不限回程班次，逛累了随时上车。这条适用于全部五条线。
- **Railcard 能省 1/3**：一人用适合自己的卡、两人用 Two Together、带孩子用 Family & Friends。具体话术直接取 `英国交通不同话术.docx`，不要自己重编。
- **住哪个区决定去哪个站**，交通话术库里有现成写法：
  - 国王十字附近 → 剑桥直接走到 King's Cross；牛津要坐 Circle/H&C 线到 Paddington
  - 罗素广场附近 → 剑桥走 Piccadilly 线到 King's Cross；牛津要 Russell Sq→Baker St 换 Circle 到 Paddington
  - 帕丁顿附近 → 牛津直接走到 Paddington；剑桥要坐 Circle 线到 King's Cross
  - 利物浦街附近 → 剑桥和哈利波特影城都可以直接走到 Liverpool Street
- 火车**出发前5分钟停止检票**，看电子屏确认站台。

## 现有成熟路线

### LDT-R01 温莎城堡

```text
08:27-09:56 酒店出发 → Waterloo 站 → Windsor & Eton Riverside
→ 10:15-13:00 温莎城堡（核心游览）
→ 13:00-14:15 温莎小镇精致午餐
→ 14:00-15:30 泰晤士河 / 伊顿小镇漫步
→ 15:30-17:30 The Long Walk 深度休闲
→ 17:30 以后 火车返回伦敦
```

调序规则：

- **门票必须提前预约**，成人£31、青年£20；现场排队可能很久。
- **换岗仪式：周二、周四、周六 11:00 开始，提前半小时占位。** 想看换岗的客户，日期必须落在这三天，且要在10:30前进城堡。
- 城堡参观需2–3小时；内部很多地方不能拍照；上午人比较少。
- 两人出行务必用 Two Together Railcard 买 Off-Peak Return。
- 已知问题：`13:00–14:15 午餐` 与 `14:00–15:30 伊顿小镇` 重叠15分钟；结尾同时有 `17:30 以后返回` 和 `16:15 以后返回帕丁顿` 两个互斥写法。调用时二选一并重排。
- **温莎闭馆安排变化较多，日期是第一优先级**，必须按客户具体日期查官网。

### LDT-R02 剑桥（宽松版）

```text
09:00-10:15 伦敦 Kings Cross → 剑桥
→ 10:15 超市买苹果
→ 10:15-11:45 抵达 → 菲茨威廉博物馆
→ 11:45-12:30 菲茨威廉博物馆（免费）
→ 12:30-13:00 数学桥 + 圣体钟（外观）
→ 13:00-14:00 市中心午餐
→ 14:00-15:30 康河撑篙（Punting）
→ 15:30-16:30 牛顿苹果树 & 剑桥排名第一的冰淇淋店
→ 16:30-17:30 Cambridge Market Square
→ 17:30-18:00 杨洋走丢伤心地打卡
→ 18:00-19:00 晚餐（剑桥／返程）
→ 19:00-20:30 剑桥站 → 伦敦 Kings Cross
```

调序规则：

- **菲茨威廉博物馆通常周一闭馆**，必须核对。免费入场。
- "杨洋走丢伤心地"是中国游客的打卡梗，客户如果不是这个圈层可以删掉。
- 已知问题：`10:15–11:45 抵达→菲茨威廉` 与 `11:45–12:30 菲茨威廉参观` 写法重复，实际是"路上+参观"，调用时合并。

### LDT-R03 剑桥（紧凑版）

同样的景点序列，但**早出发40分钟**（09:00–09:43 的快车），整天前移约1小时，18:00–19:00 就返回伦敦。

调序规则：适合当天晚上在伦敦还有安排（音乐剧、晚餐预约）的客户。

### LDT-R04 牛津（宽松版）

```text
09:30-10:15 酒店出发 → Paddington 站
→ 10:48-11:42 伦敦 Paddington → 牛津站
→ 12:00-13:00 帐篷市场（Covered Market）& 午餐
→ 13:30-15:00 基督教堂学院（Christ Church）
→ 15:00-16:00 圣玛丽教堂登塔
→ 16:00-17:00 博德利图书馆 & 叹息桥
→ 17:00-18:30 三一学院 & 晚餐
→ 18:30-19:30 爱丽丝商店 → 牛津站
→ 19:30 以后 返回 Paddington
```

调序规则：

- 基督教堂学院有牛津最宏伟的大教堂和食堂（哈利波特取景地），**强烈推荐提前购票**。
- 博德利图书馆中庭全平坦（适合老人推车）；**叹息桥下拍照注意避让自行车**。
- 购物提醒：热门景点／人流大的礼品店别冲动下单，同款商品价差很大，越热门越贵。

### LDT-R05 牛津（紧凑版）

同样序列但**早出发48分钟**（10:00–10:43），整天前移约1小时，17:00 就返回伦敦。

### LDT-R06 南安普顿

```text
09:20-09:50 酒店出发 → Waterloo 火车站
→ 10:05-11:22 London Waterloo → Southampton Central
→ 11:40-12:25 午餐
→ 12:35-13:40 SeaCity Museum（海城博物馆）
→ 14:00-14:40 Tudor House & Garden（都铎故居）
→ 14:40-15:00 中世纪城墙 & Bargate（古城门）
→ 15:00-16:00 南安普顿大学
→ 16:00 以后 Mayflower Park（五月花公园）+ 海滨散步
→ 17:00-18:17 Southampton Central → London Waterloo
```

调序规则：

- South Western Railway 每30分钟一班，持 Open Return 随意选班次回伦敦。
- 南安普顿大学要提前上官网查当月是否有开放日活动（有活动才值得进去）。
- 已知问题：模板里 `16:00–15:45` 和 `15:45–16:30` 时间倒流，调用时重排。
- 这条线适合**泰坦尼克号／海事主题**的客户，普通客户优先级低于牛津剑桥。

### LDT-R07 哈利波特影城

```text
酒店前往 Euston 站
→ 11:00-11:30 Euston → Watford Junction
→ 11:30-12:00 接驳巴士 → 影城门口
→ 12:00-13:00 影城大厅休息区午餐
→ 13:00-17:00 哈利波特影城游览
→ 17:00-18:30 返程回伦敦市区
→ 18:30-20:30 Coal Drops Yard 街区晚餐
```

调序规则：

- **影城门票必须提前很久预约**，且是按场次入场。整天从场次倒推。
- 儿童票坑：孩子在伦敦地铁通常免费，但**去 Watford 这段属国家铁路，需要在柜台买 Child Off-peak Day Return 纸质票（约£3–5）**。
- 省钱方案：四人以上去 Euston 人工柜台说 "Four people to Watford Junction"，用 GroupSave 折扣。
- 入园后在大厅买讲解器，可选中文。
- 影城内部路线（模板已给）：入口 → 大礼堂 → 室内场景 → 魔法部 → 禁林 → 9¾车站 → 餐厅 → 室外场景 → 特效展区 → 古灵阁 → 对角巷 → 霍格沃茨城堡 → 购物中心。
- 影城本身要4小时，**这天不要再塞其他景点**。

## 改这天要动哪几行

| 客户变量变了 | 要改的位置 |
|---|---|
| 住宿区域不同 | 开头"酒店→某站"整段替换，直接查交通话术库对应写法 |
| 人数／同行关系变了 | Railcard 类型跟着换（一人／两人 Two Together／带娃 Family & Friends），话术库里有现成文案 |
| 晚上在伦敦有安排 | 剑桥用 R03、牛津用 R05（紧凑版），提前约1小时回城 |
| 想看温莎换岗 | 日期必须是周二／四／六，且10:30前进城堡 |
| 温莎当天闭馆 | 整条换掉——温莎闭馆变化多，这是英国最高风险的一日游 |
| 剑桥落在周一 | 菲茨威廉博物馆闭馆，改成国王学院或叹息桥延长 |
| 带小孩去影城 | 必须单独买 Watford 段的儿童纸质票 |
| 自驾／包车抵达 | 五条线的首尾火车段全部删掉，改停车说明 |
| 住在牛津／剑桥当地 | 删首尾火车段，景点摊开成宽松一日 |

## AI 调用规则

1. 五条线结构相同，先确定**去哪、几点回**，再套模板。
2. 火车票写法（Off-Peak Day Return + Railcard）五条线通用，**从交通话术库取现成文案**，不要每条线重写。
3. 温莎的闭馆和换岗、剑桥的周一闭馆是两个最容易翻车的点，日期第一优先级。
4. 哈利波特影城当天不要加别的景点。
5. 模板里的分钟级班次都是某次订单的产物，必须按客户日期在 Trainline 或 National Rail 重查。
