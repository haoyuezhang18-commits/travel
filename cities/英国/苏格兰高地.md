# 苏格兰高地模板索引（高地／天空岛／尼斯湖／威士忌产区）

## 区域信息

- 区域：苏格兰高地
- 区域编号：HIG
- 原始模板：`城市/高地/苏格兰高地3天.docx`（3张表，10图）
- 历史遗留：本模板原名 `天空岛2天.docx`，但内含 3 张日程表、实为 3 天路线，已改为现名。旧备份里看到"天空岛2天"指的就是这一份。
- 使用原则：这是**自驾／包车路线**，三段首尾相接，住宿点分别是威廉堡、波特里、达夫镇。**制作前必须确认客户每晚住哪**，不得只写"住高地"。

## 硬约束

| 项目 | 要求 |
|---|---|
| 格伦芬南高架桥蒸汽小火车 | **8月下午班次通常15:00–15:15驶过大桥**；必须14:00前停好车并开始往观景台走，预留1小时占位 |
| 爱莲朵娜城堡 | £12/人（2025年价），通常10:00–17:00；官网提前购票便宜10%；停车£3.5/天，旺季中午容易满 |
| 老人峰（Old Man of Storr） | £12/人；停车场小，**旺季下午车位紧张，建议13:30前从波特里出发** |
| 三姐妹山／A82 | **绝对禁止为拍照把车违停在 A82 双黄线上**，交警抓违停很严；8月旺季车位极度紧张 |
| 007 同款小路 | 单车道极窄，错车必须利用左侧的 Passing Place |
| 威士忌酒厂 | 需提前预约；品鉴涉及饮酒，**自驾客户必须指定不饮酒的司机** |

日落参考：8月2日威廉堡约21:38；8月波特里约21:00–21:30。

## 现有成熟路线

### HIG-R01 第一段：格拉斯哥 → 威廉堡

```text
08:30-09:20 格拉斯哥出发 → 罗蒙湖
→ 09:20-09:50 罗蒙湖 Luss 小镇
→ 09:50-11:00 前往 007 电影同款小路
→ 11:00-11:40 Skyfall Scene 拍摄
→ 11:40-12:20 兰加布尔小屋（Lagangarbh Hut 小白房）
→ 12:20-12:40 三姐妹山沿途远眺
→ 12:40-13:40 前往格伦芬南高架桥 + 午餐
→ 13:40-15:30 格伦芬南桥等哈利波特蒸汽小火车
→ 15:30-16:15 前往威廉堡镇中心
→ 16:15-18:00 威廉堡入住及休整
→ 18:00-20:00 晚餐
→ 20:00-21:00 港口散步
```

调序规则：

- **整天的锚点是蒸汽小火车的班次**，其余全部围着它排。班次随季节变化，必须按客户日期查 Jacobite Steam Train 官网。
- 威廉堡晚餐旺季需提前官网或电话预约：The Garrison Bistro（高地本土菜、牛排、海鲜，本地人比例高，4.5分）／Black Isle Bar（精酿＋柴火披萨，4.6分）。

### HIG-R02 第二段：威廉堡 → 天空岛（波特里）

```text
09:30-10:45 威廉堡 → 爱莲朵娜城堡
→ 10:45-12:00 爱莲朵娜城堡参观
→ 12:00-12:30 爱莲朵娜城堡 → 斯凯桥
→ 12:30-13:30 抵达波特里 + 午餐
→ 13:30-14:00 波特里 → 老人峰（导航搜 Storr Car Park）
→ 14:00-16:30 老人峰经典轻徒步
→ 16:30-17:00 老人峰 → 波特里
→ 17:00-18:00 波特里小镇自由活动
→ 18:00-19:30 晚餐（波特里）
→ 19:30-20:30 波特里海港傍晚散步
```

调序规则：

- 老人峰徒步往返约2–2.5小时，路线两个方案：**高效线**（全蓝色线路，1.7公里，上山约50分钟，较陡但都是修整好的石头路）／**缓坡线**（先走黄色线路1.3公里30分钟缓坡再转）。按客户体力选。
- 老人峰停车场有公厕。
- **中午到波特里时就电话预约晚餐**，8月旺季很抢手：The Seafood Restaurant（海港边，青口和龙虾，人均£25–40）／The Granary（家庭友好，人均£20–30）。
- 波特里的彩色房子在傍晚柔和光线下最适合拍照。

### HIG-R03 第三段：波特里 → 尼斯湖 → 威士忌产区

```text
09:30-11:00 波特里 → 尼斯湖（Loch Ness）
→ 11:00-13:00 尼斯湖 → 达夫镇（Dufftown）
→ 13:00-13:30 酒店办理入住
→ 13:30-14:30 午餐（达夫镇）
→ 14:30-16:30 威士忌酒厂参观体验
→ 16:30-17:30 斯佩塞小镇探索
→ 17:30-18:00 酒店休整
→ 18:00-19:30 晚餐（达夫镇／阿伯劳）
```

调序规则：

- 首选酒厂 **GlenAllachie（格兰纳里奇）**：Aberlour 附近，从达夫镇开车约10分钟；传奇酿酒师比利·沃克执掌；参观亮点是橡木桶讲解和专业品鉴（含滴水品酒法）。
- 小镇餐厅不多，**建议提前电话预约**。
- 尼斯湖在这一版只是"路过"（09:30–11:00 一段车程里），客户如果想坐尼斯湖游船或看厄克特城堡，要另加1.5–2小时，相应压缩酒厂。

## 改这天要动哪几行

| 客户变量变了 | 要改的位置 |
|---|---|
| 不从格拉斯哥出发 | R01 开头替换（爱丁堡出发要多约1小时） |
| 住宿点不同 | **三段的住宿分别绑定威廉堡／波特里／达夫镇**，客户住别处时整段的首尾都要重写 |
| 只有2天 | 砍掉 R03（威士忌产区），R02 结束后直接返回因弗内斯或格拉斯哥 |
| 不自驾（包车） | 停车、Passing Place、违停提醒全部删掉，改为司机沟通事项 |
| 想坐尼斯湖游船 | R03 要加1.5–2小时，酒厂改成只品鉴不参观 |
| 客户想喝威士忌 | 自驾时必须指定不饮酒司机，或改包车 |
| 蒸汽小火车季节性停运 | R01 的核心锚点没了，高架桥改成外观拍照，整天时间释放 |
| 月份不同 | 日落时间重算（8月约21:30，冬季16:00前就黑），徒步和拍照时段全部跟着动 |
| 天气不好 | 老人峰徒步和三姐妹山远眺都要写替代方案，高地天气变化极快 |

## AI 调用规则

1. 这是一条 **3 天** 路线（旧文件名"天空岛2天"会误导，已改名）。制作前先数清楚客户有几天。
2. 三段各自绑定一个住宿点，**必须写清楚每晚住哪**，不能只写"住高地"。
3. R01 的蒸汽小火车、R02 的老人峰车位是两个硬时间点，先卡它们。
4. 高地天气变化极快，每段都要有天气替代方案。
5. 自驾提醒（Passing Place、A82 双黄线违停、Paybyphone 停车 App）必须写进客户文件。
