## 城市信息

- 城市：威尼斯

- 使用原则：4张表分别是“廉航抵达＋彩色岛”“佛罗伦萨抵达＋主岛”“主岛一日＋转场”“彩色岛＋玻璃岛全日”。先确定客户住主岛还是Mestre，再选表。

## 硬约束：住宿位置决定一切

**Santa Lucia 站 = 主岛；Mestre 站 = 陆地。** 这是威尼斯模板里最容易出错的一点：

- 从佛罗伦萨／罗马来的高铁到 Santa Lucia（主岛）。
- 去米兰的车、以及部分夜车，从 **Mestre 出发**，需先从Santa Lucia坐一站火车（约10分钟，班次密集）到Mestre。
- 住Mestre的客户，每天进出岛都要算上火车＋水上巴士的时间。
- 模板原话：“你们要去的米兰火车是从Mestre站出发，不是在Santa Lucia站坐车。”

其他硬约束：

| 项目 | 要求 |
|---|---|
| 水上巴士 | 进岛第一件事买48小时通票；**上船前必须在码头打卡机打票**，否则罚款 |
| 贡多拉 | 官方统一价：白天9:00–19:00 €90/船（约30分钟），**按船不按人**，最多5人，只收现金 |
| 圣马可教堂 | 教堂本身免费，看黄金马赛克／黄金祭坛必须买基础入场票 |
| 蜗牛府螺旋楼梯 | 门票约€7，藏在极窄小巷，**必须全程开导航**（Scala Contarini del Bovolo） |
| 彩色岛 | ATM很少，很多小店只收现金，提前备欧元 |
| 圣马可广场 | **严禁喂鸽子（罚款极高）**；扒手最多，包背胸前 |

## 现有成熟路线

### VCE-R01 廉航抵达＋彩色岛线

```text
巴黎奥利机场（ORY）→ 威尼斯（10:20-12:05飞行）
→ 机场→Mestre站
→ 酒店寄存＋午餐
→ Mestre→进岛→码头（火车€1.5＋买48h船票）
→ 向彩色岛出发
→ 15:30-18:00 布拉诺岛拍照
→ 返回主岛
→ Cannaregio区晚餐
→ 穿过老城返回Mestre
```

调序规则：

- **廉航柜台通常提前40分钟关闭**，模板要求08:30前到机场。
- 机场至Mestre的票，上车前要在候车区**黄色机器**打卡激活。
- 去彩色岛必须带外套，海风很大。
- 布拉诺岛往岛深处走，避开码头的团客。

### VCE-R02 主岛精华一日（佛罗伦萨抵达版）

```text
佛罗伦萨SMN→威尼斯Santa Lucia（09:30-12:00）
→ 存行李／入住
→ 宪法桥＆赤足桥
→ 佩萨罗宫外观
→ 午餐
→ 里亚托桥＋Suso冰淇淋
→ 沉船书店（Acqua Alta）
→ 15:30-16:30 贡多拉体验
→ 圣马可广场＆教堂＆叹息桥
→ 蜗牛府螺旋楼梯
→ 学院桥日落
→ 主岛晚餐
```

调序规则：

- **学院桥是威尼斯最美日落机位**（木桥＋安康圣母大教堂剪影）。威尼斯日落约18:50（该版本对应月份），建议18:30前到位。东侧看大运河延伸，西侧看教堂剪影。
- 冰淇淋 I Tre Mercanti 的百年提拉米苏**下午4点后常售罄**，路过要先买，不要等下午。
- 贡多拉推荐码头：圣马可广场Zara旁（船队最大，以里亚托桥为背景）／圣莫伊塞教堂旁（人少上船快）。平替方案是€2的Traghetto摆渡船。
- Caffè Florian在圣马可广场拱廊下，咖啡€10–15含演奏费，适合拍照。

### VCE-R04 彩色岛＋玻璃岛全日（含夜火车衔接）

```text
退房→火车站寄存全部行李
→ Fondamenta Nove码头
→ 10:15-11:00 ACTV 12路至布拉诺（约45分钟）
→ 爱情观景桥
→ 圣马蒂诺教堂
→ 蕾丝博物馆
→ Galuppi主街＋作曲家铜像广场
→ 运河彩色房屋＋后街
→ 蕾丝手作店＋Bussolà曲奇店
→ 午餐
→ 自由活动补拍
→ 14:30-15:05 前往玻璃岛（穆拉诺）
→ 玻璃工厂吹制演示
→ 玻璃博物馆／工艺品店
→ 河边闲逛
→ 返回主岛火车站取行李
→ 前往Mestre站
→ 晚餐＋候车
→ 22:36 夜火车前往慕尼黑
```

调序规则：

- 这是**四段式行程**（主岛→布拉诺→穆拉诺→Mestre夜车），转场多，任何一段延误都会压缩后面。
- 布拉诺岛上有居民正常生活，拍照别骚扰居民、别闯私人区域。
- 纪念品别在码头附近买（贵且质量一般），往岛内走货比三家。
- 玻璃制品认准 **“Vetro Artistico Murano”** 标识，路边小摊很多非威尼斯制造。
- 夜火车22:36发车，提前30分钟到站即可，但行李要在17:15前从主岛取回。

## AI 调用规则

1. **先确认住主岛还是Mestre**，再选模板。这决定每天的进出岛时间和最后一天从哪个站走。
2. 跨城车次的出发站（Santa Lucia还是Mestre）必须在客户文件里写清楚，这是本城最高频的事故点。
3. R03结构混乱，只借景点顺序，时间轴全部重算。
4. 日落时间按月份重查；学院桥占位时间要跟着日落走。
5. 贡多拉写进文件时必须注明“按船€90、最多5人、只收现金”，否则客户会按人头理解价格。
