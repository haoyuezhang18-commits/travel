# 米兰模板索引

## 城市信息

- 城市：米兰
- 城市编号：MIL
- 原始模板：`意大利/米兰/米兰一天通用.docx`（3张表）
- 使用原则：米兰全部是一日模板，三个版本的区别只在**抵达方式和是否进《最后的晚餐》**，景点池完全相同。先确定这两件事，再选版本。

## 硬约束

| 项目 | 要求 | 影响 |
|---|---|---|
| 《最后的晚餐》（恩宠圣母院） | **提前2个月官网预约**，€15/人，每场限15分钟 | 定不到就整条删掉，不要写成"可选" |
| 米兰大教堂＋登顶 | 官网预约，预约16:30须16:15前到；支持支付宝 | 决定下午骨架 |

其他固定信息：大教堂不能露肩（带薄披肩）；露台没有卫生间，上去前先解决；门票别丢，出口可能查。

## 现有成熟路线

### MIL-R01 威尼斯抵达版（半日）

核心景点：和平之门、森皮奥内公园、斯福尔扎古堡、布雷拉画廊、米兰大教堂、埃马努埃莱二世拱廊、恩宠圣母院、运河区。

```text
08:40-11:20 威尼斯→米兰中央站
→ 午餐
→ 和平之门与公园
→ 古堡与布雷拉画廊
→ 14:00-16:30 米兰大教堂＆拱廊
→ 16:30-17:30 恩宠圣母院（《最后的晚餐》）
→ 运河区晚餐
```

调序规则：

- 恩宠圣母院走 M1 地铁：Duomo 上车、Conciliazione 下车，约15分钟。
- 购物在 Rinascente 文艺复兴百货（大教堂旁，品牌集中、可统一退税，顶楼餐厅俯瞰 Duomo 屋顶），适合时间紧的客户。
- 已知问题：`13:30–14:00 古堡与布雷拉画廊` 只给30分钟，两个景点根本走不完；`12:20–13:00 和平之门` 之后到 13:30 有空档。调用时把古堡改成外观快拍（约30分钟）或整体后移。

### MIL-R02 悠闲一日版（住米兰）

```text
09:30-10:00 酒店→和平之门
→ 10:00-11:30 和平之门→森皮奥内公园
→ 11:30-12:30 斯福尔扎古堡→布雷拉
→ 12:30-14:00 布雷拉漫步＋意式午餐
→ 14:00-16:00 米兰大教堂＋内部与登顶
→ 16:00-17:00 埃马努埃莱二世长廊＋休息
→ 17:00-18:00 恩宠圣母院（观画）
→ 18:00-20:00 运河区（Navigli）漫步
→ 20:00-21:30 运河区 Aperitivo 晚酌
→ 夜色电车返回酒店
```

调序规则：

- 这是**节奏最舒服的一版**，客户住米兰一晚且不赶车时优先用它。
- 九月底运河区日落很美，沿河岸走1–2小时看两岸酒吧灯光亮起。
- 森皮奥内公园一带遇到围在一起像变魔术的立刻绕开，是骗子在找目标；路边弹唱的可以停。

08:00-13:00 罗马自驾往米兰（约6小时）

调序规则：

- **必须先安排还车再进城**：ZTL 禁行，罚款€80–300。停车白线为免费限时。
- 特种兵省钱点：周三大教堂门票单买€8。
- 已知问题：`16:00–17:00` 有一个小时空档。

## AI 调用规则

1. 先确认两件事：**从哪来**（威尼斯火车／罗马自驾／住米兰）和**《最后的晚餐》有没有票**。这两件事就能唯一确定用哪版。
2. 三个版本的景点池完全相同，只选一版，不要跨版拼接。
3. R01 和 R03 都有已知空档／过紧段，照抄会露馅，调用时重算。
4. 大教堂登顶与《最后的晚餐》一天装不下两个，必须二选一，或砍掉古堡与布雷拉。
5. 景点不在清单中：自行查询并新写，标记"新增内容"。
