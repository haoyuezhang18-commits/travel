# 罗马＋梵蒂冈模板索引

## 城市信息

- 城市：罗马（含梵蒂冈）
- 城市编号：ROM
- 主要原始模板：`意大利/罗马/罗马通用.docx`（7张表）
- 补充模板：`意大利/罗马/罗马入境模板.docx`、`意大利/梵蒂冈/梵蒂冈通用.docx`
- 使用原则：罗马模板里同一批景点被排过至少4种不同顺序，必须按客户的预约时段重新组织，不能照抄某一版的时间轴。

## 现有成熟路线

### ROM-R01 抵达罗马（FCO落地）

```text
落地FCO T3
→ 入境＋取行李（约1小时）
→ Leonardo Express至Termini（约32分钟）
→ 酒店入住
→ 酒店周边简单晚餐
```

调序规则：

- 机场进城四种方式：自助售票机／人工柜台／Trenitalia App／机场大巴（Terravision或SIT，约50–60分钟，现场€9、线上€7，可能堵车）。
- Leonardo Express单程€14，**上车前必须在站台绿色打票机激活**，否则查票罚款。车票不限班次。
- 落地第一晚不追网红店，Google Maps搜Ristorante看评分即可；进门先看菜单确认价格，避开无标价餐厅，结账核对是否含Coperto服务费。

### ROM-R02 斗兽场＋古罗马广场＋南线（跨城抵达日用）

```text
佛罗伦萨→罗马（08:30-10:00）
→ 酒店寄存行李
→ 斗兽场
→ 午餐
→ 古罗马广场＋帕拉蒂尼山
→ 真理之口
→ 威尼斯广场
→ 万神殿
→ 特莱维喷泉（许愿池）
→ 深度晚餐
```

调序规则：

- 景区内动线（模板已验证，**这段顺序不要改**）：斗兽场 → 从票面序号7的Portale del Vignola进帕拉丁山侧门（不走回头路、不爬楼梯）→ 下来就是凯旋门 → 古罗马广场 → 从6号后门出去就是真理之口 → 威尼斯广场。
- 真理之口约17:50停止排队、18:00关闭；夏季（5–9月）通常09:30–18:00，最后入场在关门前约10分钟。每人限拍一张，现场严格限时10–30秒。
- 帕拉蒂尼山正午完全无遮挡，景区内有免费直饮水栓，进景区前备好大瓶水和遮阳帽。
- 威尼斯广场后方有观光电梯直达顶部，360度视野比圣彼得更集中。
- 许愿池傍晚是**罗马第一偷盗重灾区**，包必须背在胸前。

### ROM-R03 西班牙阶梯＋许愿池＋万神殿线（市区纯玩一日）

```text
西班牙阶梯
→ 特雷维喷泉（许愿池）
→ 午餐（万神殿附近）
→ 万神殿（内部，需预约）
→ 手工特色小店
→ 纳沃纳广场
→ 威尼斯广场
→ 真理之口
→ 斗兽场外围机位
→ 帕拉蒂尼山＋古罗马广场
→ 蒙蒂街区
→ 博尔盖塞公园＋苹丘日落
→ 晚餐
```

已知问题（**必须重排**）：

- 模板里 `14:20–15:15 万神殿→纳沃纳广场` 与 `14:15–15:00 威尼斯广场` 时间完全重叠。
- `16:30–17:00 帕拉蒂尼山＋古罗马广场` 只给30分钟，与R02里给的2小时严重矛盾；同时 `16:30–18:00 斗兽场→蒙蒂街区` 又和它重叠。
- 结论：这一版的下午段是坏的。调用时保留景点组合和上午顺序，下午按R02的景区动线和真实时长重算。

其他规则：

- 西班牙阶梯**严禁坐下或吃东西**，有警察巡逻吹哨，站着拍即可；台阶上递玫瑰花或编手绳的一律不接。
- 苹丘（Terrazza del Pincio）是全罗马最著名的日落观景台，俯瞰人民广场和圣彼得穹顶。**日落时间必须按月份查**：6月下旬约20:45，8月约20:15–20:30。提前30分钟到场占位，山顶风大带薄外套。

### ROM-R04 罗马两日版

- Day1（下午抵达）：FCO → Termini存行李（KiPoint地下一层，前5小时约€10/件）→ 快速午餐 → Circo Massimo站 → 真理之口 → 帕拉蒂尼山＋古罗马广场 → 斗兽场（16:30场）→ 特拉斯提弗列区晚餐 → 斗兽场夜景（备选）。
- Day2（全天市区）：西班牙台阶 → 许愿池 → 纳沃纳广场 → 午餐 → 万神殿（13:15场）→ 圣依纳爵堂 → 威尼斯广场 → 科尔索大道＋人民广场 → 苹丘日落 → 人民广场周边晚餐。

调序规则：

- 罗马餐厅晚上**19:30才开始营业**，热门小店必须一开门就去排。晚餐不要排在19:00之前。
- 斗兽场外围主动找你合影的“角斗士”一律不理，合影后会强行索要€20–50。
- 老城核心区避开门口极度热情拉客、或菜单只有英文没有意大利文的店。

### ROM-R05 梵蒂冈日（早场博物馆版）

```text
07:20-07:50 酒店出发→梵蒂冈博物馆（地铁A线Ottaviano站，出站步行8分钟）
→ 08:00-11:30 梵蒂冈博物馆＆西斯廷礼拜堂
→ 午餐
→ 圣彼得广场＆柱廊
→ 13:00-15:00 圣彼得大教堂（登顶＋内部）
→ 伴手礼采购
→ 15:30-17:30 圣天使堡
→ 台伯河畔漫步
→ 台伯河畔晚餐
```

调序规则：

- 登顶优先于内部：先登顶（电梯€10／楼梯€8），再看内部约30–40分钟，进门右手边是米开朗基罗《哀悼基督》。
- 圣天使堡**可以只看外观不进去**；机位是从梵蒂冈往圣天使堡方向走，导航Monumento di Santa Caterina da Siena，在小贩摊位背后爬上去（台阶高，注意安全）。
- 台伯河边人流混杂、小偷较多。

### ROM-R07 离境罗马（含退税）

```text
Termini→FCO T3（08:00-08:32或08:15-08:47，€14，绿色机器打卡）
→ 退税（Tax Refund Area，靠近200-300号值机柜台）
→ 值机与托运
→ 安检
→ 出关（人工柜台盖离境章）
→ 候机登机
```

调序规则：

- **顺序是先退税、再托运**，无论退税物品在行李箱还是随身。
- 罗马机场已数字化退税：巴黎／意大利买的商品直接自助机扫护照，成功即完成。
- **瑞士段的退税不能在罗马办**：必须在离开瑞士进入意大利的边境（如Domodossola站）找海关盖戳，否则罗马海关无法处理。跨瑞士的行程一定要提前告知客户。
- 人工柜台盖完离境章，退税流程才算彻底完成。
- 罗马查随身行李很严，小登机箱也常被强制托运，相机和贵重首饰务必随身。
- 13:05起飞的航班，模板要求09:30前到机场（给退税留时间）——按客户实际航班倒推，国际航班留足3.5小时。

## AI 调用规则

1. **先定门票，再排路线。** 斗兽场联票、万神殿、梵蒂冈博物馆的场次决定整天骨架，不能反过来。
2. 同一景点在R02／R03／R04里被排过三种顺序——只选一版，不要混用。R03的下午段有已知冲突，优先用R02的景区动线。
3. 模板里的日落时间（6月20:45、8月20:15）和开放时间都是某次订单的产物，必须按客户月份重查。
4. 梵蒂冈日单独成天，不要和斗兽场挤在同一天。
5. 景点不在清单中：AI自行查询并新写，标记“新增内容”。
