# 圣米歇尔山模板索引

## 区域信息

- 区域：圣米歇尔山（Mont-Saint-Michel）
- 区域编号：MSM
- 原始模板：`欧洲/欧洲城市汇总版本.docx`（MSM-R01）
- 使用原则：**巴黎当日往返的一日游**，全天 06:30 出发、21:00 才回到酒店，是巴黎周边最长的一条日间往返线。

## 硬约束

| 项目 | 要求 |
|---|---|
| 高铁 巴黎→雷恩 | SNCF Connect **提前买票**；从 Gare Montparnasse 出发，**车站很大，预留 20 分钟找站台** |
| 雷恩→圣米歇尔山 专线大巴 | **先查大巴班次！** 出火车站左转就是大巴站（Gare Routière） |
| 回程大巴 | **依然要掐准班次**，建议提前 10 分钟到站台 |
| 摆渡车 | 免费，5 分钟一班；体力好也可以走过去（约20分钟） |

**整天有四段交通首尾相扣（高铁→大巴→摆渡车→原路返回），任何一段误点都会连锁。班次必须按客户日期全部重查。**

## 现有成熟路线

### MSM-R01 圣米歇尔山一日（巴黎当日往返）

```text
06:30-07:00 早起出发 → Gare Montparnasse（地铁或打车，预留20分钟找站台）
→ 07:30-09:00 高铁：巴黎 → 雷恩（TGV，1.5小时，车上有充电插座可补觉）
→ 09:15-10:30 专线大巴：雷恩 → 圣米歇尔山（1小时15分）
→ 10:30-11:00 免费摆渡车抵达山脚（5分钟）
→ 11:00-12:30 草地拍照点（导航 Méandres）
→ 12:30-14:30 游览修道院
→ 14:30-15:30 小镇逛街＋下山
→ 16:00-17:15 回程大巴：山脚 → 雷恩
→ 18:00-19:30 回程高铁：雷恩 → 巴黎
→ 19:30-21:00 巴黎 1 区晚餐
```

调序规则：

- **草地拍照点是精华机位**：导航定位 `Méandres`，就是那张著名的、带草地和羊群背景的圣米歇尔山全景。模板给了 1.5 小时，不算多。
- **修道院内部是精华，千万别错过**（模板原话）。跟着大部队往山上走，石子路较多，**穿好走的鞋**。
- 晚餐推荐法式油封鸭（Confit de Canard）补体力——走了一天，这个建议很实际。
- 这条线**全天在外 14.5 小时**，带老人小孩要慎重，或者改成在山脚住一晚。

## 改这天要动哪几行

| 客户变量变了 | 要改的位置 |
|---|---|
| 带老人／小孩 | 14.5 小时太长，建议改成**在山脚或 Beauvoir 住一晚**，把行程拆成两天 |
| 想看涨潮／夜景 | 模板是当日往返看不到，**必须住一晚**；圣米歇尔山夜景和大潮是它最出名的两件事 |
| 自驾 | 删掉高铁和大巴段，改停车说明（山脚有大型停车场，同样要坐摆渡车进） |
| 从雷恩或圣马洛出发 | 删掉巴黎段，整天轻松很多 |
| 冬季 | 日照短，草地机位光线时间要提前；大巴班次冬季减少，必须重查 |
| 想省钱 | 大巴＋高铁联票有时比分开买便宜，出行前在 SNCF Connect 比价 |

## 模板缺什么

- **涨潮时刻表**：圣米歇尔山的大潮是核心看点之一，模板完全没提。想看要查官方潮汐表并配合日期。
- **住宿版本**：只有当日往返版，没有住一晚的版本。
