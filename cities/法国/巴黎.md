# 巴黎模板索引

## 城市信息

- 城市：巴黎
- 城市编号：PAR
- 主要原始模板：`法国/巴黎/巴黎行程通用计划.docx`（10张日程表）
- 资源型模板：`法国/巴黎/巴黎不同区餐厅.docx`、`法国/巴黎/巴黎购物店铺.docx`
- **⚠ 多天套装**：文件内部分了「巴黎两天通用」和「巴黎3天通用」两节。两天版用 `PAR-R03-A` + `PAR-R02`；三天版从 `PAR-R05-A` 起。
- 使用原则：先选一条最接近客户天数和抵达方式的成熟路线，再改日期、人数、交通和景点顺序。10张表里有大量重复段落，不要拼接。

## 四个大馆的闭馆日互相咬死，排法基本唯一

客户要卢浮宫＋凡尔赛＋奥赛＋（迪士尼等每日开放项目）时，先列矩阵：

| | 周日 | 周一 | 周二 | 周三 |
|---|---|---|---|---|
| 卢浮宫 | ✅ | ✅ | ❌闭馆 | ✅ |
| 橘园 | ✅ | ✅ | ❌闭馆 | ✅ |
| 凡尔赛 | ✅ | ❌闭馆 | ✅ | ✅ |
| 奥赛 | ✅ | ❌闭馆 | ✅ | ✅ |

**周一是最差的一天**（奥赛、凡尔赛、橘园同时闭馆），把每日开放的项目（迪士尼、蒙马特、铁塔、塞纳河游船）放在周一。**周二只能去凡尔赛或奥赛**，卢浮宫和橘园必须放在周日／周三／周一。

奥赛周四延长开放到 21:45，卢浮宫周三和周五有夜场——晚场可以用来救回被闭馆挤掉的项目。

## 现有成熟路线

### PAR-R01 抵达巴黎（CDG落地）

```text
07:20-09:30 落地、入境与进城
→ 09:30-11:00 酒店寄存
→ 之后接入 R02 或 R05
```

调序规则：

- 模板只写到“寄存行李”，落地当天的后半天必须自己接一条轻量路线（推荐R05奥赛线或R02圣母院线）。
- 必须使用客户真实机场（CDG／ORY／BVA）、航站楼和抵达时间。CDG走RER B约30–35分钟／€11.80；打车Uber约€50–70。
- 长途飞行落地当天不排卢浮宫、凡尔赛这类高强度项目。

### PAR-R02 圣母院＋玛黑区＋歌剧院＋百货线

```text
巴黎圣母院
→ 莎士比亚书店
→ 咖啡馆休憩
→ 玛黑区午餐
→ 巴黎歌剧院（Palais Garnier）
→ 老佛爷／巴黎春天百货
→ 铁塔附近晚餐
```

调序规则：

- **巴黎圣母院必须提前2–3天在 App（Notre-dame de paris）零点刷新预约**，每15分钟一个时段。这是全天最硬的锚点，先定它再排其他。
- 巴黎歌剧院参观票必须官网提前买，现场排队极长；周日开放10:00–17:00，门票约€15，参观约1.5小时。
- 玛黑区的Bouillon République环境好价格亲民，但**必须官网预订，且周五晚／周六全天关门**——落在周五周六必须换餐厅。
- 玛黑区买手店周四开门晚，安排上午逛街要避开。
- 退税在巴黎春天办比老佛爷人少；巴黎春天男装馆7楼天台免费且无玻璃遮挡，拍全景比老佛爷好。

### PAR-R03-A / R03-B / R03-C 卢浮宫＋橘园＋凯旋门＋蒙马特线

> 原始 DOCX 里这条线有三张表：`PAR-R03-A`（两天版D1）、`PAR-R03-B`（3天版D3）、`PAR-R03-C`（完整版，含蒙马特与老佛爷夜景）。景点池相同，**取时长最接近客户的一版**。

```text
卢浮宫（3–3.5小时）
→ 午餐（Café Marly／Le Florentin）
→ 杜乐丽花园
→ 橘园美术馆
→ 凯旋门＆香榭丽舍
→ 蒙马特高地＋圣心堂＋爱墙＋画家广场
→ 蒙马特晚餐
→ 老佛爷／奥斯曼大道夜景（可选）
```

调序规则：

- 卢浮宫三宝在德农馆：蒙娜丽莎（2楼711室）、胜利女神、维纳斯。预留3小时以上，不要为塞景点压缩。
- 橘园的莫奈《睡莲》**必须提前官网预约**。
- 凯旋门登顶需提前买票；只拍外观则时间很短。
- 蒙马特：圣心堂周日6:00–22:30免费入内；教堂门口是扒手重灾区，**遇到强行套红绳／手绳的立即走开**；缆车可刷Navigo Easy。
- 这条线也可拆成两天（卢浮宫＋橘园一天，凯旋门＋蒙马特一天）。

### PAR-R04 凡尔赛宫＋蒙马特＋百货线

```text
08:30-09:00 前往凡尔赛宫
→ 09:00-13:00 凡尔赛宫
→ 返回巴黎＋午餐
→ 蒙马特高地＋爱墙
→ 老佛爷百货
→ 晚餐
```

调序规则：

- 凡尔赛占据整个上午，必须早出发；模板给4小时，含往返交通实际要留5小时。
- 凡尔赛宫周一闭馆，具体日期必须查官网。
- 蒙马特与老佛爷距离不近，模板给20分钟转场偏紧。

### PAR-R05-A / R05-B 奥赛＋铁塔＋塞纳河游船线（落地当天用）

> 两张表：`PAR-R05-A`（3天版D1）、`PAR-R05-B`（当天落地即玩版，含铁塔闪灯与日落游船）。

```text
11:00-13:30 奥赛博物馆
→ 左岸午餐
→ 向铁塔方向辐射漫步
→ 埃菲尔铁塔＆夏乐宫（日落机位）
→ 铁塔平价晚餐
→ 夜游塞纳河游船
```

调序规则：

- 这是**倒时差友好版**，适合上午落地当天。
- 夏乐宫（Trocadéro）平台是拍铁塔全景的最佳日落机位。
- **铁塔闪灯秀：日落后天黑开始，每小时整点闪5分钟金光**，第一场约20:00前后（夏季可能21:40日落／22:00首闪）。要看闪灯必须按当月日落时间倒推，不能照抄模板时刻。
- 落地第一晚有时差，塞纳河晚上风大，注意保暖。

### PAR-R06 铁塔＋凯旋门夜景线（跨国抵达当天用）

```text
抵达里昂站→酒店入住
→ 香榭丽舍大道＋凯旋门
→ 埃菲尔铁塔外观＋战神广场日落
→ 铁塔周边晚餐
→ 铁塔闪灯秀＋塞纳河夜景
```

调序规则：

- 适用于从瑞士／意大利坐火车下午抵达里昂站的日子。
- 铁塔机位清单（模板已标P1–P5）：3 Port Debilly（P1）／花店18 Av. Rapp（P2）／游船Bateau Mouche上（P3）／Bateau Boréas楼梯石墙（P4）／战神广场大草坪（P5）／特罗卡德罗广场。
- 日落时间必须按月份查：10月初约19:10，8月约21:00，需提前30–40分钟到场占位。

### PAR-R07 离境巴黎

两个版本：

- **飞机离境**：圣母院 → 莎士比亚书店 → 玛黑区午餐 → 老佛爷／巴黎春天 → 回酒店取行李 → RER B至CDG → 国际航班提前3小时到机场。
- **火车离境**：退房寄存（酒店前台或里昂站负一层Consigne人工寄存）→ 圣母院 → 书店 → 咖啡 → 歌剧院 → 晚午餐 → 15:30前往里昂站 → **16:00必须到大厅看大屏幕核对站台**。

调序规则：

- 按航班／车次倒推，不要先塞景点再算交通。
- 回酒店取行李的，要在出发前至少45分钟从景区动身。
- 离境日只排可随时中断的项目，不排需要预约的入内项目。

## 餐厅库与购物库的调用规则

`巴黎不同区餐厅.docx` 和 `巴黎购物店铺.docx` 是**按区索引的资源库，不是行程**。

- 餐厅库覆盖1、2、3、4、5、6、7、8、9、18区，每区按“法式本地／亚洲风味／甜品烘焙／咖啡Brunch／异国风味”分类。
- 购物库按“1区／2-4区文艺寻宝／5-7区设计师折扣／8-18区潮流复古／3区&9区文艺设计／4区&5区文艺书香／18区&景点周边”分组，并单列伴手礼。
- 调用方式：确定当天行程落在哪个区，再去对应区段挑1–2家写进当天备注，**不要整段复制整个区的清单**。
- 库里已标注需要预订的店（Bouillon République、Arrivederci pizzeria、蒙马特米其林等），凡标“建议提前预定”的，写进客户文件时要保留这句提醒。

## AI 调用规则

1. 客户需要的景点在上述清单中：打开原始模板对应表格，直接复用详细内容，再改客户变量。
2. 同一景点在多张表里重复出现（圣母院、卢浮宫、老佛爷出现4–5次）：**只选与客户天数最接近的一张表**，不要跨表拼接。
3. 景点不在清单中：AI自行查询并新写，明确标记“新增内容”。
4. 涉及餐厅或购物时，先查两个资源库有没有现成条目，没有再新写。
5. 所有日落时间、闪灯时间、开放时间必须按客户实际月份重查，模板里的时刻只是某一次订单的产物。
