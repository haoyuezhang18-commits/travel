## 现有成熟路线

### PRG-R01 老城／新城线（河东）

核心景点：查理大桥、市立图书馆书塔、天文钟、老城广场、泰恩教堂、火药塔、哈维尔市场、卡夫卡雕像、悬挂的小人、跳舞的房子。

```text
08:30-09:30 查理大桥（Karlův most）
→ 09:30-09:45 市立图书馆（网红书塔）
→ 09:45-10:45 天文钟（Orloj）＋登钟塔
→ 10:45-11:15 老城广场＋泰恩教堂（外观）
→ 11:30-12:00 火药塔（Prašná brána）
→ 13:00-14:00 老城区午餐
→ 14:00-15:00 哈维尔市场（Havel Market）
→ 15:00-15:20 罗浮宫咖啡馆（爱因斯坦同款）
→ 15:30-16:00 卡夫卡雕像
→ 16:00-17:00 悬挂的小人（Hanging Man）
→ 17:30-18:30 跳舞的房子（Tančící dům）
→ 18:30-20:00 沿河岸往回走
→ 20:00-20:20 查理大桥（傍晚版，补拍日落照）
→ 20:20-21:20 晚餐
```

调序规则：

- **查理大桥安排了早晚两次是刻意设计**（早上人少拍空景、傍晚拍日落），不要当成重复景点删掉。
- 桥上小贩和扒手多，包背胸前。
- 书塔由8000本书堆成，从底部仰拍像无限深渊。
- 捷克菜分量很大，点菜提醒客户别浪费。
- 晚餐：Pork's（Mostecká 16，查理大桥步行1分钟，脆皮猪肘，人均€10–20，饭点需排队或预约）／U Glaubiců（查理大桥城门附近，酸奶油炖牛肉＋烤肋排，人均€18–20）。
- 已知问题：`12:00–13:00` 有空档；`15:20–15:30` 和 `15:30–16:00` 都写"→卡夫卡雕像"，重复。调用时合并。

### PRG-R02 城堡／小城线（河西）

```text
08:30-09:15 酒店→布拉格天文馆
→ 09:15-11:30 布拉格天文馆（Planetarium）
→ 11:30-12:00 天文馆→布拉格城堡

→ 13:30-14:30 小城区（Malá Strana）漫步

→ 14:30-15:30 免费观景台
→ 15:30-16:00 布拉格城堡区（Pražský hrad）
→ 16:00-17:00 圣维特大教堂
→ 17:00-17:30 城堡→列侬墙
→ 17:30-18:00 列侬墙（Lennonova zeď）
→ 18:00-18:30 小城区闲逛
→ 18:30-20:00 小城区晚餐
```

调序规则：

- 已知问题（**这张表要重排**）：`13:30–14:30` 同时写了"小城区漫步"和"华伦斯坦花园"两项，时间完全重叠；`12:30–13:30` 是空档；城堡区只给30分钟、大教堂1小时，实际城堡区（含旧皇宫、黄金巷）至少要2小时。
- 建议重排为：天文馆（可选，对天文没兴趣可删）→ 城堡区（2小时）→ 圣维特大教堂 → 黄金巷 → 下山经小城区 → 华伦斯坦花园 → 列侬墙 → 晚餐。
- 免费观景台注意扒手。
- 圣维特花窗下午光线最好，所以大教堂放下午是对的，重排时保留这一点。
