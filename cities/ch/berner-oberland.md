# 瑞士伯尔尼高地模板索引（因特拉肯／格林德瓦／劳特布龙嫩／施皮茨）

## 区域信息

- 区域：伯尔尼高地（Berner Oberland）
- 区域编号：BEO
- 原始模板：
  - `瑞士/因特拉肯/因特拉肯模板.docx`（4张表）
  - `瑞士/格林德瓦/格林德瓦通用.docx`（5张表）
  - `瑞士/劳特布龙嫩/因特拉肯滑翔伞→劳特布龙嫩.docx`（1张表）
  - `瑞士/施皮茨/施皮茨通用.docx`（1张表）
- 合并成一页的原因：这四个镇在同一个交通网内（Interlaken Ost 是枢纽），客户住哪个镇决定用哪套模板，但景点池是共用的。**不要按镇分别读四份模板然后拼接。**

## 先确定这三件事

1. **住哪个镇？** 格林德瓦（离少女峰最近）／因特拉肯（交通枢纽、镇大）／劳特布龙嫩（瀑布山谷）。住宿位置决定每天的第一段和最后一段交通。
2. **哪天上少女峰？** 少女峰是全区唯一的整日项目，且旺季强制预约座位，先定它。
3. **有没有Swiss Pass／半价卡？** 有无通票直接改变购票方式和成本写法。

## 硬约束

| 项目 | 要求 |
|---|---|
| 少女峰（Jungfraujoch） | 官网 jungfrau.ch 提前购票，**旺季强制预约座位，现场可能买不到**；也可Grindelwald Terminal柜台或SBB App |
| First缆车 | 营业约8:00–17:30，注意末班时间 |
| 瑞士超市 | **周日基本全关，平日约18:30关门**；饮用水和路餐要在火车站便利店（如Interlaken Ost站内Avec）解决 |

| 山顶气温 | 少女峰3454米、瑞吉山1797米，即使夏天也要防风外套；10月山顶约5–10℃ |

## 现有成熟路线

### BEO-R01 卢塞恩→格林德瓦抵达日

```text
卢塞恩火车站（10:24）
→ 格林德瓦（13:10，黄金列车约2h45m）
→ 酒店入住
→ 格林德瓦午餐
→ First缆车站
→ 15:00-16:00 First山（可选）
→ 缆车下山
→ 16:15-17:15 梦幻山坡深度拍照
→ 超市采购（可选）
→ 格林德瓦晚餐
```

调序规则：

- 格林德瓦有多个站，**一般住镇上是在Grindelwald主站下车**，提前确认酒店靠近哪个站。
- 晚餐推荐：Barry's（氛围好，需官网预订）／Memory（必点Eiger-Rösti，CHF 25–40）／Glacier（雪山view）／C und M（披萨意面简餐）。
- 超市采购要卡在关门前，周日尤其。

### BEO-R02 少女峰日（格林德瓦出发，标准版）

```text
09:00-09:30 酒店→Grindelwald Terminal
→ 购票＋候车
→ 10:00-10:15 Terminal→艾格冰川站（Eigergletscher）
→ 10:15-10:45 换乘少女峰齿轨列车→少女峰顶站（约26分钟）
→ 10:45-14:00 少女峰顶游览
→ 14:00-14:30 返回艾格冰川站
→ 14:45-15:30 返回格林德瓦，午休
→ 15:30-18:00 小镇漫步
→ 格林德瓦晚餐
```

调序规则：

- **上山坐右侧座位**，可看艾格峰、僧侣峰、少女峰全景。
- 山顶必看：①斯芬克斯观景台（高速电梯直达，360度俯瞰阿莱奇冰川）②冰宫（地面极滑，走慢点）③高原Plateau（户外踩雪，风大保暖）④少女峰全景电影。
- 下山人多，提前15分钟到车站排队。
- 这一版把First和少女峰分在两天，节奏最舒服。

### BEO-R03 少女峰＋First同日版（因特拉肯出发）

两个变体，区别在先后顺序：

- **少女峰在前**：因特拉肯→格林德瓦（07:30–08:30）→ 09:00–13:30少女峰 → 格林德瓦快捷午餐 → 15:30飞椅 → 16:15山地卡丁车 → 17:00梦幻山坡 → 18:00超市 → 晚餐。
- **First在前**：因特拉肯→格林德瓦 → **09:00前必须到First索道站**（否则排队会拖垮少女峰）→ 09:15飞椅 → 10:15卡丁车 → 11:30午餐 → 13:00梦幻山坡 → 14:00–15:30登少女峰 → 15:30–17:30少女峰之巅 → 经Wengen返回 → 因特拉肯晚餐。

调序规则：

- **不要在First山上吃午饭，又贵又慢**（模板原话），下山到格林德瓦吃。
- 一天塞两个山非常紧，只推荐给体力好、且天气确认晴朗的客户。First在前的版本对时间更敏感，09:00是死线。
- 周日超市18:30准时关门；周日午餐建议12点前到免排队。

### BEO-R04 梦幻山坡（独立拍照模块）

```text
15:50-18:40 梦幻山坡拍照
```

调序规则：

- 定位 Dorfstrasse 60, 3818 Grindelwald 的 First Garage 加油站，**加油站西边的小路往下走两步即到**。
- **不用坐缆车**，村里徒步可达。适合不赶行程、专门拍照的客户。
- 这是个可插入模块，不是完整一天。

### BEO-R05 滑翔伞＋劳特布龙嫩瀑布日

```text
08:30-09:00 前往滑翔伞集合点（Interlaken Ost站对面COOP超市门口）
→ 09:00-10:30 滑翔伞飞行（巴士上山＋飞行约1.5h）
→ 回酒店取行李
→ 因特拉肯午餐
→ 12:00-12:20 因特拉肯东站→劳特布龙嫩
→ 车站存行李
→ 12:35-13:35 施陶河瀑布（Staubbach）
→ 141路公交（约10分钟，CHF 3.60，每20分钟一班）
→ 13:45-15:30 特吕默尔巴赫瀑布（Trümmelbach）
→ 取行李
→ 16:01-19:25 劳特布龙嫩→日内瓦
→ 日内瓦入住＋晚餐
```

调序规则：

- 滑翔伞公司：Skywings（冠军教练团队，评分4.9，允许自带GoPro，夏季集合点Schuh餐厅前Höheweg 56）／Paragliding Interlaken（1990年至今，瑞士最老牌，集合点Interlaken Ost对面COOP门口）。**订的是哪家就用哪家的集合点**，不要混。
- 提前1小时到集合点。
- 滑翔伞受天气影响，必须给客户写“如取消的替代方案”（建议：直接去劳特布龙嫩延长瀑布时间）。

## AI 调用规则

1. 先定住宿镇和少女峰日期，其余按天填。
2. 少女峰票和滑翔伞是两个需要提前预订的项目，必须写进文档2的预约汇总表。
3. 山上项目全部要写“天气不佳的替代方案”，瑞士山区行程不写替代方案等于没做。
4. 所有缆车、齿轨、游船的末班时间必须按客户日期在SBB App重查，模板时刻只是参考。
5. 涉及周日的行程，必须检查超市和餐厅营业状态。
