# 阿姆斯特丹模板索引

## 城市信息

- 城市：阿姆斯特丹
- 城市编号：AMS
- 原始模板：`欧洲/欧洲城市汇总版本.docx`（AMS-R01、AMS-R02）
- 使用原则：R01 是从根特经布鲁塞尔转场抵达的日子，R02 是全天（上午郊外风车村、下午市区）。

## 硬约束

| 项目 | 要求 |
|---|---|
| 郊外火车票 | **别去柜台，下 NS App 买票**，往返 €7.6，能省 €1；往 Uitgeest 方向坐 |
| 运河船 | **必须选全透明玻璃顶的船**——不去博物馆没关系，但运河是阿姆的灵魂 |
| 红灯区 | **眼睛随便看，手机别乱拍**，否则手机会被扔进水里 |
| 水坝广场 | 人多，看好手机和包 |

## 现有成熟路线

### AMS-R01 布鲁塞尔半日＋抵达阿姆斯特丹（根特出发转场日）

```text
07:30-08:00 根特退房
→ 08:04-08:45 根特 → 布鲁塞尔（IC 火车，抵达 Brussels Central）
→ 08:45-09:00 站内自动柜寄存行李（不要带去景点）
→ 09:00-09:30 布鲁塞尔大广场
→ 09:30-09:45 撒尿小童（顺手买个瓦芙饼当早餐）
→ 09:45-10:15 圣休伯特拱廊街（快速买 Neuhaus 巧克力）
→ 10:15-10:40 艺术山（台阶上俯瞰大广场尖塔，拍完直接走回车站）
→ 10:40-11:00 取行李＋进站
→ 11:03-13:53 布鲁塞尔 → 阿姆斯特丹（跨国火车）
→ 14:00+ 阿姆斯特丹入住
→ 15:30-17:00 水坝广场（皇宫、新教堂、街头艺人）
→ 16:30-17:30 薯条＆苹果派
→ 17:00-18:30 西教堂附近散步（安妮之家方向，王子运河边）
→ 18:30-20:00 晚餐（豌豆汤 Erwtensoep 或印尼菜）
```

调序规则：

- **一到布鲁塞尔中央站立刻寄存行李**，四个景点全在步行 5–8 分钟范围内，是刻意设计的紧凑环线，行李会拖垮节奏。
- **部分快车可能在 Midi 站发车，核对票面**，别默认 Central。
- 与英国的布鲁塞尔模板（`BRU-R01`，巴黎北站当日往返）景点相同但节奏完全不同：那份是悠闲一日，这份是 1 小时40 分钟速通。按客户实际停留时长选。
- 已知问题：`16:30–17:30 薯条苹果派` 与 `17:00–18:30 西教堂散步` 重叠 30 分钟，调用时重排。

### AMS-R02 阿姆斯特丹一日｜风车村＋运河船＋九街

```text
09:00-09:30 出发去郊外（NS App 买票，往 Uitgeest 方向）
→ 09:30-10:15 乐高小镇（Zaandam 站下，拍照就撤）
→ 10:15-13:00 风车村深度游（Zaandijk 站下走15分钟入村）
→ 13:00-14:00 买巧克力回城（Blik Cacao）
→ 14:00-15:00 运河船（全透明玻璃顶）
→ 15:00-16:30 辛格花市＋九街苹果派（Winkel 43）
→ 16:30-18:00 水坝广场打卡
→ 18:00-19:30 晚餐（Pancake Bakery 或印尼菜 Rijsttafel）
→ 19:30-20:30 红灯区
```

调序规则：

- **乐高小镇和风车村同方向、同一张票**，出站依然有效——这是省钱和省时的关键，写进备注。
- 风车村必看：进门先过桥；打卡木鞋店门口的大黄鞋、时钟博物馆。
- Henri Willing 奶酪随便试吃；羊奶冰激凌很滑，**不爱吃甜的千万别加那个配料**。
- **Winkel 43 的苹果派全城第一，必须吃**，模板在两条路线里都提到了它。
- 印尼菜（Rijsttafel）是荷兰特色，一桌几十个小碟子，视觉冲击力强。
- 已知问题：`10:15–13:00` 同时写了"风车村深度游"和"奶酪＋冰激凌"两行，是同一时段的并列内容，不是两件事，调用时合并。

## 模板缺什么

**阿姆斯特丹最著名的三个博物馆模板里一个都没有**：梵高博物馆、国立博物馆（Rijksmuseum）、安妮之家。客户十有八九会点名，且都需要提前预约。做这座城市时要有心理预期：多半要新写半天到一天。

## AI 调用规则

1. 先确认从哪来：根特／布鲁塞尔方向用 R01，已在阿姆用 R02。
2. **三大博物馆模板里没有**，客户一提就是新增内容且要提前预约。
3. NS App 买票、同一张票覆盖乐高小镇和风车村——这两条省钱经验直接复用。
4. 红灯区的"别拍照"提醒必须原样写进客户文件。
