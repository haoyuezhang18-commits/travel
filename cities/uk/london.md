## 现有成熟路线

### LON-R01 西敏经典线

核心景点：

- 白金汉宫
- 圣詹姆斯公园
- 唐宁街10号
- 白厅
- 威斯敏斯特教堂
- 大本钟
- 议会大厦
- 伦敦眼
- 海德公园（按当天时间选择）

#### 有换岗仪式的日期

目前常用调度经验为周一、周三、周五优先安排白金汉宫换岗，但制作具体日期时必须查看官方当天日历，确认是否举行或因天气、王室活动等原因取消。

默认顺序：

```text
上午：白金汉宫换岗
→ 圣詹姆斯公园
→ 唐宁街10号／白厅

下午：威斯敏斯特教堂
→ 大本钟
→ 议会大厦
→ 伦敦眼
```

#### 没有换岗仪式的日期

默认顺序：

```text
上午：威斯敏斯特教堂
→ 大本钟
→ 议会大厦
→ 伦敦眼

下午：白金汉宫外观
→ 圣詹姆斯公园
→ 海德公园
```

调序规则：

- 初步框架中的上午、下午只是参考，以换岗和威斯敏斯特教堂开放时间为准。
- 没有换岗时，白金汉宫仍可安排外观拍照，但优先放到下午。
- 威斯敏斯特教堂周日通常不作为普通游客观光开放，具体日期必须查官网。
- 伦敦眼如果只是外观拍照，停留时间较短；如果实际乘坐，需要另加排队、安检和乘坐时间。

### LON-R02 大英博物馆＋国家美术馆线

默认顺序：

```text
大英博物馆
→ 午餐
→ 科文特花园
→ 国家美术馆
→ 特拉法加广场
→ 摄政街／牛津街／Soho
→ 晚餐
```

调序规则：

- 大英博物馆内容较多，不要为了加入更多景点而随意压缩。
- 国家美术馆和特拉法加广场相邻，应连续安排。
- 摄政街、牛津街、皮卡迪利广场可根据客户购物需求选择，不要求全部加入。

### LON-R03 圣保罗＋博罗市场＋塔桥线

默认顺序：

```text
圣保罗大教堂
→ 千禧桥
→ 泰特现代美术馆（可选）
→ 博罗市场
→ 泰晤士河南岸
→ 塔桥
→ 塔桥附近晚餐
→ 碎片大厦（可选）
```

调序规则：

- 博罗市场尽量放在午餐时段，不要安排得过早或过晚。
- 圣保罗大教堂周日通常不作为普通游客观光开放，必须核对日期。
- 泰特现代美术馆、伦敦塔和碎片大厦按客户兴趣及时间选择，不自动全部加入。
- 泰晤士河游船可以替代西敏至塔桥的一段地面交通，但需要重新计算码头、班次和下船位置。

### LON-R04 诺丁山＋购物线

默认顺序：

```text
白厅／骑兵换岗（按需求）
→ 午餐
→ 诺丁山
→ 科文特花园（按需求）
→ 摄政街
→ 牛津街
→ Soho晚餐
→ 西区音乐剧（可选）
```

调序规则：

- 诺丁山和市中心购物区距离较远，应预留交通时间。
- Portobello Road Market是否值得重点安排取决于具体日期和营业情况。
- 音乐剧有固定开演时间时，倒推晚餐和购物结束时间。

### LON-R05 福尔摩斯主题线

默认顺序：

```text
Brunch
→ 贝克街221B福尔摩斯博物馆
→ 福尔摩斯酒吧
→ 特拉法加广场
→ 摄政街
→ Soho晚餐
```

调序规则：

- 可作为抵达伦敦后的轻量主题路线。
- 如果客户不是福尔摩斯爱好者，不应占用完整一天。
- 福尔摩斯博物馆入内与只拍外观需要区分。

### LON-R06 抵达伦敦

默认结构：

```text
机场落地
→ 入境／取行李
→ 前往伦敦市区
→ 酒店寄存或入住
→ 简单用餐
→ 根据抵达时间决定休息或轻量游览
```

调序规则：

- 必须使用客户真实机场、航站楼和抵达时间。
- 英国酒店通常15:00后入住；提前抵达写寄存行李。
- 不同机场的进城方式不可混用：希思罗、盖特维克、斯坦斯特德和卢顿分别核对。
- 长途飞行抵达当天不要默认安排高强度景点。

### LON-R07 离境伦敦

默认结构：

```text
酒店早餐／退房
→ 寄存行李
→ 轻量活动或补漏
→ 取行李
→ 前往机场
→ 办理登机及安检
```

调序规则：

- 根据国际航班建议到达机场时间倒推，不先塞景点再计算交通。
- 机场、航站楼、行李数量和交通方式必须使用客户真实信息。
- 离境日景点只安排可随时结束的项目，不安排难以取消的长时间入内项目。

### LON-R08 格林威治线

默认顺序：

```text
伦敦市区码头
→ 泰晤士河游船
→ Cutty Sark外观／入内（按需求）
→ 皇家海军学院
→ 河畔午餐
→ 格林威治天文台
→ 格林威治公园／市场
→ 返回伦敦市区
→ 晚餐或音乐剧（可选）
```

调序规则：

- 先确认上船码头、下船码头、班次和单程／往返。
- 天文台位于坡上，需考虑步行体力。
- 音乐剧有固定时间时，必须倒推返程游船或公共交通时间。

## AI 调用规则

1. 客户需要的景点在上述清单中：打开对应原始模板，直接复用已有详细内容，再修改客户变量。
2. 景点名称在多条成熟路线中重复：选择与客户需求最接近的一条成熟路线，不重复复制相同景点。
3. 客户需要的景点不在清单中：AI自行查询并新写内容，明确标记为“新增内容”。
4. 新写内容经人工确认后，只需将景点名字加入本清单；不要求为每个景点建立复杂资料卡。
5. 广场、街道、拍照点、餐厅和商店通常保留在路线中，不单独建立景点资料卡。
6. 泰晤士河游船、伦敦眼乘坐等可插入多条路线的项目，按可选模块使用，但仍只在本页记录名称和调度规则。
