# 根特模板索引

## 城市信息

- 城市：根特（Gent）
- 城市编号：GNT
- 原始模板：`欧洲/欧洲城市汇总版本.docx`（GNT-R01）
- 关联：从根特出发的转场日见 [`../荷兰/阿姆斯特丹.md`](../荷兰/阿姆斯特丹.md) 的 `AMS-R01`（根特→布鲁塞尔半日→阿姆斯特丹）
- 使用原则：这是**巴黎大巴抵达当天的傍晚半日**，不是完整一日。根特的精髓在夜景，模板刻意把行程放在傍晚到夜里。

## 硬约束

| 项目 | 要求 |
|---|---|
| FlixBus 巴黎→根特 | 长途大巴约 4.5 小时，**受路况影响**，抵达时间要留余量 |
| 香草河岸（Graslei） | **趁天没黑到**，拍彩色阶梯屋顶和落日 |
| 夜景 | 根特夜景获过奖，是这座城市的核心卖点 |

## 现有成熟路线

### GNT-R01 根特（巴黎大巴抵达＋古城夜景）

```text
10:30-11:15 退房 → 大巴站
→ 11:35-16:05 跨国：巴黎 → 根特（FlixBus，约4.5小时）
→ 16:05-16:30 下车＋先去酒店放包
→ 16:30-18:00 香草河岸（Graslei）——趁天没黑看彩色阶梯屋顶、拍落日
→ 18:00-19:30 古城三塔连线（钟楼、圣巴冯大教堂）＋晚餐
→ 19:30-20:30 伯爵城堡夜景
→ 20:30-21:30 夜游根特古城
```

调序规则：

- **提前准备好水和充电宝**——4.5 小时长途大巴，模板专门提醒。
- 大巴站通常在火车站附近，**建议先去酒店放包再进城**。
- 傍晚的顺序是按光线排的：**香草河岸看落日 → 三塔连线 → 伯爵城堡夜景 → 夜游**。天黑时间随季节变化极大（夏季 21:30、冬季 16:30），**冬季必须整体前移，或者放弃落日只看夜景**。
- 晚餐推荐 Amadeus（当地有名的猪肋排）或奶油炖鸡。
- 伯爵城堡就在河边，晚上灯光效果非常出片，适合散步消食。

## 模板缺什么

- **圣巴冯大教堂内部和根特祭坛画**（《神秘羔羊之爱》，凡·艾克兄弟）——根特最著名的艺术品，模板只安排了外观。需预约、需时约 1 小时。
- 布鲁日（Brugge）：距根特火车约 25 分钟，是比利时最热门的小镇，**模板完全没有**。客户来比利时多半会问。

## AI 调用规则

1. 这是傍晚半日模板，不是完整一日；客户住两晚要补内容。
2. 全天顺序按光线排，**天黑时间按月份重算**，这是唯一的时间锚点。
3. 根特祭坛画和布鲁日是两个明显缺口，客户提出即新增内容。
