## 一、景点票务与预约

| 城市 | 景点 | 购票方式 | 预约 / 购票链接 | 使用日期 | 核心提醒 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

**填写要点**

- 购票方式两列并存：**官网** + **国内平台**（携程／飞猪搜什么关键词），客户按习惯选。
- 核心提醒写死线，例如：`必须提前30天官网抢票`／`需带护照原件实名入场`／`16:00最后入场`／`周一闭馆`。
- 按日期升序排，同一天多个景点排在一起；**同城连续的行，城市列留空**，只在换城时写。
- **免费景点也要写进来**，标"免费无需预约"，客户才知道这项不用操心，而不是以为漏了。
- **提前期最长的排最前面**，或单独在表头上方写一行：`⚠ 需最早预订：XXX（提前2个月）`。

常见提前期（详见 [`../docs/欧洲通用避坑规则.md`](../docs/欧洲通用避坑规则.md)）：

| 提前期 | 项目 |
|---|---|
| 2个月 | 米兰《最后的晚餐》、维也纳歌剧院演出 |
| 30天 | 罗马斗兽场联票 |
| 数天 | 巴黎圣母院（App零点刷新）、跨国高铁 |
| 官网提前即可 | 梵蒂冈、乌菲兹、温莎城堡、爱丁堡城堡、新天鹅堡、少女峰、柏林国会大厦 |

## 二、跨城 / 市内交通票务

| 日期 | 行程 | 交通方式 | 购票渠道 / 链接 | 关键提醒 |
|---|---|---|---|---|
|  |  |  |  |  |

**填写要点**

- 行程写**站名全称**：`伦敦 King's Cross → 约克`、`威尼斯 Mestre → 米兰 Centrale`。
- 关键提醒里必须覆盖：
  - 英国：Railcard 类型（省 1/3）、Off-Peak Day Return
  - 意大利：**纸质票站台绿色机器打卡／电子票 App 内 Check-in，否则重罚**
  - 跨国：建议提前 3–7 天购票、检票时间比国内长
  - 景观位：坐左还是坐右（模板里已验证的都写上）
- 站台号不写死，写"进站看大屏幕确认站台"。

## 三、住宿推荐

| 城市 | 入住 | 退房 | 住宿等级 | 酒店 / 区域 | 选择理由 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

**填写要点**

- 选择理由要具体到动线：`离 King's Cross 步行5分钟，去爱丁堡/约克/剑桥都从这个站走`。
- 客户已订的照抄不改，只在理由列写"客户已订"。
- **入住退房按晚数写**（`9/24-9/30（6晚）`），客户一眼能核对总晚数。
- 酒店名写成可直接复制到携程搜索的形式。
