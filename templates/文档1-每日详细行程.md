## 开头：每日一行概述

**全部天数确认完成后才生成，不得从旧框架生成。**

```text
✓ 9/24 伦敦：圣保罗大教堂，千禧桥，博罗市场，塔桥，晚《汉密尔顿》
✓ 9/25 伦敦：威斯敏斯特教堂，大本钟，伦敦眼，白金汉宫换岗
✓ 9/26 剑桥：菲茨威廉博物馆，康河撑篙，国王学院，牛顿苹果树
```

写法：`✓ 日期 城市：景点，景点，景点，晚间安排`。一天一行，不换行不分点。

## 正文：每天一张四列表

### Day N｜M/D（周X）城市

| 时间段 | 行程内容 | 交通/方式 | 核心备注 |
|---|---|---|---|
| 09:00 - 09:30 |  |  | ● <br>● |
| 09:30 - 12:00 |  |  | ● <br>● |
| 12:00 - 13:30 | 午餐 |  | ● 餐厅：<br>● 人均：<br>● 是否需预约： |
| 13:30 - 15:30 |  |  | ● |
| 15:30 - 17:00 |  |  | ● |
| 18:00 - 20:00 | 晚餐 |  | ● 餐厅：<br>● 人均：<br>● 是否需预约： |
| 20:00 以后 |  |  | ● |

**填写要点**

- 核心备注用 `●` 分点，一个操作一点，不要合并成整段。
- 每天必须有午餐和晚餐行。
- 需要预约的项目，在备注第一点就写清楚"必须提前 X 天在 XX 官网预约"。
- 可选项目在行程内容里写成 `（可选）XXX`，不单独解释。
- 抵达日提前到店写"寄存行李"，不写"入住"。
- 涉及班次的写清出发站全名（如"威尼斯 Santa Lucia 站"而非"威尼斯站"）。
